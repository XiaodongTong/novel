# 刘波（主角）

> 主角档案。冲突时以 ../base/spine.md + ../base/world 为准。

---

## 基本信息
- **姓名**：刘波
- **年龄**：17岁（穿越后这具身体）
- **前世**：现代急诊科医生，39岁，值了无数夜班，见过人间冷暖
- **身份**：万仙宗外门杂役弟子 → （Arc1后）被逐/逃亡 → **云游道人（凡间伪装身份，不坐堂、不留姓、不挂大夫名号）** → 万家城核心人物
- **灵根**：五灵根（"废灵根"），常规体系下的最底层。**但在夺根基禁术体系里反而最优**——五灵根残片五行俱全，是唯一能和天灵根暗伤"全谱兼容"的药引材料（"最废"与"最优"是同一枚硬币）。这是他被顾长缨**定向猎杀**的根源：他不是随机名单上的一个，是顾长缨攒多年才等到的、不可替换的最上等药引。详见 ../base/world/00-世界观总纲.md §九 与 05-夺根基禁术.md。
- **修为**：随剧情推进，走常规修炼体系。**前段七弧最高停在筑基大圆满**（金丹突破留后期主线）。**实力是主角第一要务**——实力 = 修为 + 功法 + 法宝 + 攻击 + 防御 + 逃跑 + 幻术 + 阵法（八维）。境界推进慢但八维总和涨得飞快，**可越阶战斗**（短时可正面战金丹后期/元婴初期、逃元婴中期）。**无体系外挂**——古物只精准辅助，不直接赐予境界。

## 金手指
- **照墟玦**：被设局取材、逃入后山禁地（上古封印地）濒死时抓住，钻入掌心，共生不可去。前期刘波不知道此名，只当它是一块古物；内有一位被封印大能的残魂。
- **能力**：三重视界（看见运行规则/被掩盖的真相/人心阴谋），成长型解锁。详见 ../base/world/01-古物与金手指.md。
- **代价**：看见=暴露，深看招未知存在清理。详见 ../base/world/03-底层法则.md。
- **关键**：照墟玦**不给战斗力**。他强在"看得清"，不在"走得和别人不一样"。

## 性格
**夹缝求生的权谋型主角。看破不说破是他的生存本能。**

- **冷静、克制、算计、能忍**。情绪很少外露，永远在判断（这话是不是陷阱？这人能不能信？）。
- **外表**：装傻/装木讷/装废灵根。看起来人畜无害，甚至有点窝囊。
- **内心**：锋利、警觉、多疑。比所有人都多知道一件事，但永远不说。
- **底色是善良**——但这份善良永远要给"活下去/护住在乎的人"让路。他能救人，但救人前会先算清代价。
- **会报复、会撒谎、会布局**。不是圣人。对设局把他当药引取材的顾长缨，他恨得发冷，能忍到时机成熟再一刀。
- **穿越者的傲慢**：总觉得比这世界聪明（多数时候对），这让他低估本地人的恶意，反复吃亏。
- **多疑到孤立**：因为"看破不能说破"，他谁都不敢全信（连照墟玦里的大能都不能信），越来越孤独。

## 前世医术（重要：降级处理 + 不挂大夫名号）
- **医术是前世技能、凡间副业**，用于处理凡人/妖兽生物体的伤病（创伤、中毒、生理结构修复），塑造人物底色。**但不是他的凡间公开身份**——他以"云游道人"行走凡间，不坐堂、不开药铺、不留大夫名号。凡人对他救苦的认知来自**降妖除祟+灾厄化解**，不来自医术。
- **绝不**用于：识破功法、降维修士、看穿经脉、诊断修炼问题。这些全部由古物的"看见"承担。
- **治疗生物体（凡人/妖兽的疾病、创伤、中毒、生理结构修复等）属于"医生救人"本能的合法使用**——这是凡间医学能力，不触发降维修仙界禁令。**降维禁令只针对：识破功法/看穿经脉/诊断修炼问题/借医术判断修炼状态。** Arc3 刘波用医术救妖父（治疗生物体创伤）属于合法，不算降维。
- **医术作为性格弱点**用：他戒不掉"救人"的本能。这会被敌人利用，也会让他一次次冒险。自谦口头禅"贫道不过略通岐黄"是他给自己的提醒——也是一种自我保护（装无害）。

## 主线欲望
**活下去——把实力提上来——并且搞清楚：**
1. 照墟玦是什么，它为什么选中我。
2. 这世界的真相到底是什么（每一次"看见"都让他更想弄明白）。
3. 我到底能不能，不被它（照墟玦里的大能）和它们（未知存在）一起，吃掉。

**这是私人化的、求生驱动的欲望，不是"拯救苍生"。** 拯救是路上撞见的、被迫承担的副产物——他不主动当救世主，但每次看见有人要被害，他的医者本能+善良底色会逼他出手，哪怕有暴露风险。

**最核心驱动（第零项）**：**实力是命根子。** 看破不说破是前期不得已的手段——实力不够，看见再多也只能憋着。他要的不是当一个聪明的杂役一辈子，是**有朝一日能正面打回去**。从 Arc2 逃出万仙宗起，实力大计正式提上日程——**实力 = 修为 + 功法 + 法宝 + 攻击 + 防御 + 逃跑 + 幻术 + 阵法**（八维）。修为只是其中一维。前段七弧最高停在筑基大圆满，但**八维领先同阶**，**可以越阶战斗**——苦修不止，奇遇不放，每次打怪算计都要有收获、有成长。详见 [04-修炼成长.md](../base/world/04-修炼成长.md)。

## 实力成长曲线（前段七弧）

> 详细节奏锚点见 [spine.md §六.A](../base/spine.md) 与 [04-修炼成长.md §三、§四](../base/world/04-修炼成长.md)。
> **核心设计**：境界推进慢（只到筑基大圆满），但**八维总和涨得飞快**——这是越阶战斗的根本。

| Arc | 境界起→终 | 越阶上限 | 关键八维进账 | 性格变化 |
|---|---|---|---|---|
| 1 禁地与眼 | 炼气一 → 炼气一 | 战同阶；逃炼气三 | 古物觉醒；看穿；装无害；屈辱期家底攒不下 | **屈辱期**：求生为先；离宗瞬间立誓"必须把实力提上来——修为/功法/法宝/法术，全要" |
| 2 蝼蚁的眼 | 炼气一 → **炼气大圆满** | 战筑基初期（借刀）；逃筑基中期 | **真功法残卷+卧底法宝+借三角阵杀阵+宋清漪资源** | **起步期**：苦修+卧底战利品。"我能修、我能打"的自信第一次建立 |
| 3 点化 | 炼气大圆满 → **筑基初期** | 战筑基中期；逃筑基后期 | **筑基突破+御物短飞+真功法初用+学初阶阵法+本命飞剑胚胎** | **筑基期**：第一次有"修士"的实质感。妖父子见证苦修 |
| 4 棋子 | 筑基初期 → **筑基中期** | 战筑基后期；短时逃金丹初期 | **本命飞剑炼成+护盾法宝+完整真功法+借阵杀阵升级** | **痛中跃升期**：实力体系首次成型；但救不回死人——实力线最深的反讽 |
| 5 香火 | 筑基中期 → **筑基后期** | 战筑基大圆满/金丹初期；逃金丹中期 | **学幻影分身+布筑基级杀阵+暗除恶妖批量碾压同阶** | **综合爆发期**：第一次正面打金丹初期；六维叠加碾压 |
| 6 被注视的眼 | 筑基后期 → **筑基后期·满**（故意压境界）| 战金丹中期；逃金丹后期 | **上古真功法+上古法宝+自创"看见反用"型幻术** | **博弈期**：从大能那里偷真东西；从"被喂的"变成"偷喂自己的" |
| 7 真相与火 | 筑基后期·满 → **筑基大圆满**（顿悟）| **短时战金丹后期/元婴初期；逃元婴中期** | **自创心法+八件法宝成体系+顿悟级幻术+筑基大圆满阵法** | **顿悟期**：实力第一次"属于他自己"（自创心法是核心）；揭破"信仰喂照墟玦"——存在性危机 |

### 关键性格-实力咬合
- **Arc1-2**：弱→不弱。从"我是个废"到"我能修+我能打"，自信开始建立。
- **Arc3-4**：不弱→强。第一次有了实质战斗力，但 Arc4 ch72 痛失让他明白"强=能救"是错觉——**有时候强了也救不回来**。这是他从"利己求生"转向"必须更强、且更冷"的转折。
- **Arc5-6**：强→更强。开始有主动选择权，但**敌人也水涨船高**。从被动接受古物的"喂饵"变成主动从古物里偷东西。Arc6 故意压境界、偷上古真东西——博弈正式赢一次。
- **Arc7**：强 + **自创心法**（真正属于他的实力）+ 看清楚自己有多少是被喂的——存在性危机的修炼版。后期主线"《照墟》"的内在张力起点。

### 越阶能力·性格底色
刘波的"越阶"永远靠**八维叠加**，不是凭单一爆发。这与他的性格深度一致：
- **多疑** → 永远多准备一两手（一件法宝、一道阵法、一个幻影分身、一个逃命方案）
- **冷静** → 不孤注一掷，能跑就跑、能借刀就借刀
- **算计** → 永远比对手多算一步——这是看见+布局，也是他实力的核心
- **善良底色** → 救人时永远先算自身代价，但**真到临界点会用命换**——这是他八维全部燃烧的诱因（ch72 痛中跃升、Arc7 节点③ 主动深看）

## 人物弧光
- **开篇**：只想活下去的利己者。善良是底色，不是动机。**实力：屈辱期，废灵根杂役。**
- **Arc1-2**：第一次尝到"看见"的甜头，也第一次付出代价。开始意识到这世界不对劲。**实力：炼气一 → 炼气大圆满；真功法残卷+法宝+借阵杀阵；可借刀杀筑基初期。**
- **Arc3**：看破大型阴谋，被卷入棋局。从"为自己活"到"不得不为更多人活"，但抗拒扩大责任。**实力：筑基初期；本命飞剑胚胎+学初阶阵法；可正面打筑基中期。**
- **Arc4**：两面受压（外面追杀+里面大能引导），学会反过来算计大能。进入"谁都不能信"的最孤立状态。**实力：筑基中期；本命飞剑炼成+完整真功法+护盾法宝；可正面打筑基后期，短时逃金丹初期。但救不回死人——实力线最深的反讽。**
- **Arc5-6**：看清棋局全貌。面对"我也是棋子吗"的存在性危机。**实力：筑基后期（Arc6 故意压境界不破大圆满）；学幻影分身+布筑基级杀阵；Arc6 从大能那偷上古真功法+上古法宝+自创"看见反用"幻术；可正面打金丹中期。**
- **Arc7**：最终**主动选择**深看终极真相，明知会暴露。**实力：筑基大圆满（顿悟突破）+ 自创心法 + 八件法宝成体系 + 顿悟级幻术；可短时战金丹后期/元婴初期、逃元婴中期；硬扛清理第一波。揭破"信仰喂照墟玦"——他第一次怀疑这实力是不是真的属于他；唯一不被怀疑的是自创心法。**

## 弱点（戏剧发动机）
1. **穿越者的傲慢**——低估本地人的恶意与算计，反复吃亏。
2. **多疑到孤立**——谁都不信，包括该信的人，导致关键时刻无人援手。
3. **医者的强迫症**——戒不掉救人，会被利用，会冒险。
4. **对照墟玦/大能的依赖**——他越来越离不开"看见"，但每一次依赖都让他更深地陷入大能的棋局。

## 关键关系
- **照墟玦里的大能**：博弈方，非盟友。互相利用、互相防备。详见 ../base/world/02-被封印大能.md。
- **顾长缨**：设局把他当药引取材的人。Arc1的执行者。刘波恨他，但要忍到能反杀的时候。
- **沈千秋**：万仙宗秩序执行者。知道中层真相，选择维护秩序。刘波的哲学镜像。
- **宋清漪**：互相防备的同路人。她有自己的秘密/目标，刘波对她"看破不能说破"。
- **鹿啸/鹿鸣**（若保留）：凡间锚点（沧溟三十六寨某寨）。鹿啸之死（若发生）是被阴谋牵连，刘波看破却没能救——节点②素材。
