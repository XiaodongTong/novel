# 试刀人（Arc1 反派 · 功能代号）

> Arc1 那个"奉顾长缨之命来试探/处理刘波的人"。Arc1 反杀高潮的素材。
> **"试刀人"是功能代号，真名＝魏长宁**（详见 ../characters/魏长宁.md）。本档案只登记"试刀"这一功能的设计，人物全档以 魏长宁.md 为准。
> 详见 ../base/spine.md §六 Arc1 + ../base/arcs/arc1-禁地与眼.md + ../base/world/05-夺根基禁术.md。

## 基本信息（与魏长宁.md 一致，此处只列功能相关项）
- **真名**：魏长宁（Arc1 时正文暂用"试刀人"代号，真名在 Arc1 反杀高潮揭示）
- **身份**：万仙宗外门执事弟子，炼气后期，顾长缨的直属下级（执行末端）
- **修为**：炼气后期（在杂役和低阶弟子面前够用，但比内门弟子弱很多）
- **与顾长缨的关系**：直属。顾长缨是他在宗内唯一的靠山。
- **任期/双重功能**：本季度他在顾长缨清除（实为**药引收取**）体系里承担两段活——
  1. **开篇收取收尾**（老本行）：顾长缨设局把刘波骗到后山禁地边缘，他负责现场布锁魂阵、确认死透、取残片（药引收取的标准作业）。
  2. **随后的近距离试探**（本季新活）：收取失败（刘波拼死反抗逃入禁地深处+用看见骗过边缘锁魂阵）后，顾长缨要他"换一种法子，先试探、后收尾"——负责"近距离接触 + 试探 + 收集证据 + 配合顾长缨再次动手"。

## 小档案（戏剧引擎）

- **欲望**：完成本季度的考核 KPI（几单清除/收取），不被宗门怀疑、不被顾长缨甩锅，**靠手艺和可靠成为顾长缨离不开的人**。
  - **关键**：他不是求升迁，是求**不被甩锅**——他清楚自己在顾长缨眼里只是"工具末端"。他懂药引收取的手艺（布锁魂阵、用法宝确认死透、取残片），这是他立足的本钱。
- **算计**：试探刘波是否真的"有问题"，还是只是运气好没死。
  - 他会先**靠近**刘波（用"关心同门""例行询问"等借口），观察刘波的反应。
  - 他**不直接动手**——因为他需要"合理证据"才能上报顾长缨。
- **盲点**：他按"边缘者特征清单"对照刘波——清单上没写"掌心黑纹"，他**不会自己想到去看掌心**。
  - **刘波如何利用**：故意展示清单上**有的**"可疑点"（如：他那天确实在崖底待了不正常的时长、他身上沾了不该沾的灵气波动），让试刀人以为自己在查；把真实的东西（古物 / 黑纹）藏起来。
- **行为模式**：
  - **问话**：试探性问话（"那天在崖底怎么回来的？""你是不是看见什么奇怪的东西？"）。
  - **观察**：看刘波的眼神、手的位置（会不会下意识护住某处）。
  - **不擅权谋**：他是执行末端，不懂大局——所以他**容易中圈套**（刘波用看见的信息设一个"圈套"，他会以为是自己查出来的）。
- **刘波如何反制**（设计方向，写正文时定细节）：
  - 反制必须在"不暴露古物"的前提下。
  - 反制要"具体到人 + 具体到物"——比如让试刀人**自己露馅**（他一句问话暴露了他知道某件不该知道的事）。
  - 反制后刘波必须付出**章级小代价**（如：他撒谎时漏出的细节，被某旁观者记住了）。

## 与刘波的关系张力

- **试刀人看刘波**：废灵根，本不该活下来的边缘者，处理掉就完事。
- **刘波看试刀人**：用古物看见的——他眼底一闪的算计 / 他问话里的圈套 / 他背后那个**真正的命令源头**（更深一层）。
- **关键张力**：刘波用看见识破试刀人，但**不能揭穿**——揭穿 = 暴露自己有"看见"的能力 = 立刻被更上面的人盯上。
- **他必须用"装傻 + 借力 + 借刀"的方式处理**——这是 Arc1 第一次完整的"看破不说破 → 借刀 → 翻盘"循环。

---

## 与其他角色的关系

- **顾长缨**：上级，命令源。试刀人对顾长缨**怕多于忠**——他知道顾长缨会甩锅。
- **沈千秋**：他不直接接触沈千秋，但沈千秋的"秩序执行者"形象是他行为的合法性来源——他相信自己在做"对的事"。
- **其他杂役**：他把他们当"工作对象"——冷漠，按清单处理，没想过他们的名字。
- **刘波**：在他的清单上，但他**还没确认**刘波"有问题"——他以为是顾长缨多疑。

## 写作时的处理原则

1. **前期绝不让读者知道他的真名**——保留"试刀人"这个代号直到 Arc1 反杀高潮。
2. **写他的短镜头时，不解释动机**——只给动作 / 细节（如：他问话时没看刘波的眼睛，看的是刘波的手）。
3. **他不是坏人**——他是"系统的执行末端"。让他有一点点自己的内心（如：他回家后也会叹气，也会想"这活儿干完能不能歇一歇"）。
4. **反杀高潮时**——让他**自己露馅**，而不是刘波揭穿。这是"看破不说破"的最完整兑现。
