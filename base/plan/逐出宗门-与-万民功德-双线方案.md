# 逐出宗门 + 万民功德 双线方案

> **状态**：讨论稿，未落实到设定文档。
> **适用范围**：100 章后剧情主线。前 100 章仅做轻量铺垫。
> **来源**：与作者讨论形成的方案，记录于此供后续动笔前回看与调整。

## 一、缘起：书名与设定的死结

**书名**：《被逐出宗门后，我成了万民之主》——已定，不可改。

**已写章节状态**：ch1-20 已 commit。其中 ch1-15 写的是「主角装死逃出青玄宗」，不是「被逐出」。ch15 结尾顾生在凡间扎根、改名顾大夫。

**死结**：
- 当前设定中，赵玄机执行的是「清除名单」——目标就是杀。"差一点要觉醒"的废灵根必须死，留活口=清除失败。
- ch7-15 已落地的事实：顾生**伪装死亡**才脱身。在青玄宗官方记录里他已经"死"了。
- 既不是"逃出"也不是"逐出"，是"死亡注销"。
- 装死=自我抹除=送给宗门免费的杀。**杀一个不存在的人最容易**。

要让书名"被逐出宗门后"成立，必须给宗门一个**主动选择逐出而不是杀**的理由。

## 二、剧情主线 1：大后期逐出 + 主角应对

> **实施时机**：100 章以后。前 100 章绝不触发本线核心事件。
> **关键前提**：主角必须已经有一定实力与名声基础。若前期假死被宗门中高层识破，主角没有破局资本，小说逻辑上会直接完结。

### 2.1 大后期逐出—— 宗门的算计

**机制**：保留 ch1-100 主线不动。100 章以后，当主角已经有一定实力、资源、人脉和行动空间时，再让青玄宗中高层识破顾生当年的"假死脱身"，并对外正式宣布"顾生因 X 罪被逐出宗门"。

**为什么宗门要这么做**：
- 顾生"装死"逃脱后留下了**他用了古物的痕迹**（破封、伪证、王二麻僵在洞口）。秦长老一级的人物比赵玄机更精明，能拼出"顾生没死，而且身上有古怪"。
- 但秦长老**不能公开承认**清除名单的存在——清除名单本身就是中层秘密。如果宣告"我们要追杀一个废灵根"，就要解释为什么追杀，这会撕破中层的伪装。
- 所以秦长老用一个**官方说法**把顾生从"应被清除者"重新定性为"被宗门驱逐的弃徒"——给追杀套上一层合规的外皮：宗门可以以"追回弃徒/惩戒叛门"为名继续找他，又不用解释清除名单。

**用一句话总结秦长老的算计**：「这小子必须死，但不能死在『清除名单』的账上。」

### 2.2 罪名设计（用顾生 ch7-14 的脱身手段反向定罪）

| 罪名 | 出处 | 顾生当时干了什么 | 宗门怎么定性 |
|---|---|---|---|
| 勾连妖兽 | ch8-9 灰鳞兽破封 | 顾生用古物看出妖兽走位异常 | 「私通后山妖兽，谋害同门」 |
| 构陷同门 | ch10 伪证 | 顾生在主峰正堂用半真半假的话误导追查 | 「捏造证据、栽赃同门」 |
| 谋害送信师兄 | ch14 王二麻僵在阵法 | 顾生把王二麻引到旧封印 | 「将师兄诱入禁地、致其重伤神志」 |
| **私藏不明古物** | 兜底罪 | （顾生没真盗，但这条最关键） | 「私藏不明古物（具体内容讳莫如深）」——秦长老用"不便公开细节"四个字遮住一切，等于把"清除名单"用"古物泄密案"的标签包起来 |

**爽点价值**：顾生**亲手挖的脱身陷阱，被宗门正式登记成了他的"罪状"**。他成了官方文书上的"叛徒"，但他自己知道——这套罪名每一条都是他用来活命的工具。**这是另一种"看破不能说破"的延伸**：他知道这些罪是假的，但他不能解释，因为解释=暴露他还活着。

### 2.3 死局升级 —— 宗门识破"假死"

**关键节点**：后续章节中，宗门中高层识破顾生"假死脱身"的计策。与此同时，顾生也通过某种方式知道：宗门已经知道他没死。

这一步是整条线的真正死局。

顾生原本靠"假死"脱身，表面上是逃出生天，实际是把自己推入了另一种更危险的状态：

- 在青玄宗对外记录里，顾生已经是一个"不存在的人"
- 宗门中高层知道他没死，但外界不知道
- 宗门若要杀他，不需要审问、不需要审判、不需要承担明面责任
- 因为**杀一个已经死在记录里的人，最容易**

更严重的是，大后期的"公开逐出"会给宗门提供合法外壳。宗门可以同时使用两套说法：

| 场景 | 宗门说法 | 实际目的 |
|---|---|---|
| 对外 | 顾生是叛门弃徒，按宗规追剿 | 合法通缉、压住舆论 |
| 对内 | 顾生是假死逃脱的清除目标 | 继续灭口、抹掉清除名单痕迹 |
| 暗处 | 顾生已经"死"过一次，再死一次也不会有人追问 | 低成本处决 |

所以，顾生此时面临的不是单纯追杀，而是一个身份死局：

> 他越藏，越像一个不存在的人；越不存在，宗门越容易杀他。

主角必须破掉的，不是追兵，而是这个"不存在"的状态。

### 2.4 主角的破局——把自己重新变成"宗门的人"

**核心策略**：顾生要破这个死局，就必须反向操作——不能继续藏，必须把自己重新推到天下人眼前，并且给自己套上一个宗门马甲。

他要让所有人都知道：

> 青玄宗有一个叫顾生的人还活着，而且正在以青玄宗弟子的身份救苦救难。

这一步的关键不是单纯出名，而是**以宗门身份出名**。

如果顾生只是用"顾大夫"的身份行善，宗门仍然可以说：那是叛徒顾生，是假冒良善的邪修，杀了也无妨。

但如果顾生每次行事都故意亮出宗门身份，局面就变了：

- 他治病救人时，亮青玄宗令牌
- 他诛杀恶鬼、妖兽、邪修散修时，报青玄宗名号
- 他救下百姓、村镇、城池后，故意留下"青玄宗顾生"这个身份线索
- 他不只让百姓记住"顾生救了我"，更让百姓记住"青玄宗的顾生救了我"
- 他把每一桩善行都做成青玄宗的功德账

这等于是把宗门架到火上：

> 你们说我是叛徒，可以。可天下百姓都看见了，我拿的是你们的令牌，报的是你们的宗名，救的是你们治下的人，杀的是你们本该杀的邪祟。

当"青玄宗顾生"的名声越来越大，宗门就失去直接下手的空间：

- 杀他 = 杀自己刚刚扬名天下的招牌
- 否认他 = 承认青玄宗连门下弟子真假都辨不清
- 说他假冒 = 要解释为什么一个"假冒者"能拿出宗门令牌、熟悉宗门法度、长期以宗门名义行事而无人制止
- 说他是邪修 = 要解释为什么这个"邪修"救了那么多凡人、杀了那么多邪祟，而宗门此前毫无作为

**这才是顾生破局的本质**：

> 他不是躲过宗门的刀，而是把宗门的刀架回宗门自己的脸上。

**具体做法**：
- 高调借宗门名义"普渡众生"
- 治病救人、诛杀恶鬼、妖兽、邪修散修
- 每次动作都故意以宗门身份行事：亮宗门令牌、报宗门名号、留下可被传播的身份痕迹
- 把自己从"记录里已经死掉的逃徒"，重新变成"天下人都看见的青玄宗弟子"
- 总之搞到莫大的名气，让天下都知道，青玄宗有一个菩萨一样的人

**为什么有效**：
- 名声起来后，宗门就被架住了，不好下手
- 杀一个百姓口里的"菩萨"，宗门要付出巨大的舆论代价
- 聚光灯下杀人，宗门的伪装也会被撕破
- 顾生把自己的"生死"从宗门暗账里，转移到了天下人的眼睛里

### 2.5 宗门的反扑 —— 三步杀

聚光灯下宗门只好走三步：
1. **先拉拢**：对外宣称"那是我宗门的人"，把名声红利吃下来
2. **认下**：给主角加冕官方身份，表面荣耀，实则锁住主角的招牌
3. **诬陷除名**：等主角失去警惕、或找到合适借口后，诬陷罪名、公开除名
4. **继续杀**：除名之后名声反转，"菩萨"变"邪修"，宗门可以名正言顺再次追杀

**爽点结构**：这就是本线的正式"逐出宗门"。它不是前期为了对齐书名而硬补的纸面公告，而是大后期在天下人眼前发生的公开除名：宗门先被迫承认他，再亲手把他逐出去。

### 2.6 触发时机

这条剧情线要在**主角有一定实力以后触发**——
- 前期实力不够，频繁高调=直接死，连出名的机会都没有
- 至少筑基期，最好接近金丹
- 已确认：放在 100 章后启动；前 100 章不得让宗门中高层确认顾生假死未死

## 三、剧情主线 2：百姓信仰 → 功德加身

### 3.1 触发与机制概览

**触发**：主角执行剧情主线 1 的"高调普渡众生"过程中，**误打误撞**得到百姓的信仰。

**外在表现**：
- 很多人建庙烧香
- 百姓给主角封了一个酷的法号/神号，烧香祭拜
- 信仰不断累积

**内在机制**：
- 众生信仰 → 功德
- 功德 → **解锁鲜为人知的修行方式**
- 这是另一条修行路径，扩展能力
- 同时引出"万民之主"的剧情

### 3.2 神号方案：「青玄·救苦天神·顾生」

**三段式神名**（参考真实民俗如"东岳·泰山·神帝"、"南海·观世音·菩萨"——「地域/宗门 + 神格 + 本名」）：

`
"青玄" = 宗门前缀（青玄宗）
"救苦天神" = 神格名（百姓信仰的体现，宗门被迫认下）
"顾生" = 真名后缀（青玄宗的命名规范）
`

**为什么这套设计有力**：
1. "青玄"前缀的剥离是核心打脸点——它是一个**可视化的"逐出"动作**。文书上"青玄"两字被划掉的那一笔，就是书名的兑现时刻
2. 三段式名称符合修真界对神祇的命名传统——读者一看就懂这是个被纳入官方祭祀体系的神
3. "救苦天神"四个字够大、够稳——不是"菩萨"（佛系）、不是"真人"（道系），是修真界自创的神格名。"救苦"对应医者+渡人，"天神"对应他被信仰抬高到的位阶。**这名字百姓喊起来威严，江湖人听了不敢造次，宗门用起来又显得是"自己门下"——三方都接受**
4. 后期"救苦天神·顾生"的两段式留存极有力——前缀没了，神格名和真名焊死。**百姓每喊一次"救苦天神顾生"，就是在喊一次"宗门是错的"**

### 3.3 神号演化路径

`
100章前      凡间潜伏期          →  顾大夫 / 顾生（朴素自称，不触发神号线）
100章后前段  名声经营期          →  江湖杂称（活死人、黑掌神医等过渡阶段）
100章后中段  宗门被迫拉拢期      →  「青玄·救苦天神·顾生」（三段式正式神名）
100章后后段  宗门除名            →  「救苦天神·顾生」（"青玄"被划掉，但百姓焊死后两段）
`

> 章节号是基于 100 章后的相对时序，仅为示意。实际写作时按节奏调整。

### 3.4 功德机制（最终敲定版）

| 维度 | 设定 |
|---|---|
| **涨** | 信仰+香火=功德。信众越多功德越多 |
| **用** | 全给：炼丹、战斗、防护、修炼资源 |
| **失** | 已得功德**不消失**。但**民心动摇时停止增长**（不再有新功德入账） |
| **第二次逐出后** | 信仰来源断裂——功德存量还在但**不再增长**，相当于"开源被掐断"。主角必须吃老本撑过这段 |
| **后期反弹** | 教众改弦更张后（重新认主角），功德重新开始增长 |
| **副作用** | 无 |
| **与照墟玦** | 信仰滋养照墟玦（喂养大能） |

**核心张力**：
- 第二次逐出后 → 信徒动摇 → 功德开源被掐断 → 主角进入"吃老本"的危险时期
- 这段时间他必须重新经营民心，让信仰回流，重新开源
- 但他越经营，越靠近"演员"身份；越喂养，照墟玦里那位醒得越快
- **这是结构层面的两难**，不是人格层面的强加

### 3.5 与古物机制的咬合

- **古物**：窥探秩序的工具，看见真相会引来未知存在的清理（凿洞）
- **功德**：群体信仰编织的认知噪音
- **互动**：信仰**滋养照墟玦里的大能**——主角以为自己用信仰救命，实际上每一柱香都在喂养照墟玦里那位
- **后期反转**：主角发现自己以为是给自己套马甲，**实际上每涨一点信仰，照墟玦里那位就快醒一分**。当大能彻底苏醒时，主角才发现自己一直在给自己挖坟
- 这条机制呼应 SPINE 第三层钩子："主角的金手指本身是陷阱"

### 3.6 主角弧光（保持开放）

**不预设主角后期内心走向**——
- 不预先决定他是"演一辈子的演员"、"演着演着成真的"还是"始终拒绝菩萨身份"
- 让真实人格走向由具体章节的真实选择长出来
- 我们只搭舞台，不规定他在舞台上怎么演

## 四、双线咬合关系

剧情主线 1 与剧情主线 2 不是平行的两条线，是**同一条线的两个层次**：

`
剧情主线 1（外层结构，100章后）：
  前期装死逃出并长期潜伏 → 大后期宗门识破假死
  → 宗门以"逐出/追剿"外壳制造身份死局
  → 主角破局：高调以宗门名义普渡众生
  → 宗门被架住，先拉拢→认下→诬陷→除名→继续杀
  → 正式逐出宗门（书名兑现）

剧情主线 2（内层机制）：
  普渡众生过程中 → 误打误撞得百姓信仰
  → 立庙烧香+神号→功德加身
  → 解锁另一条修行路径
  → 引出"万民之主"
  → 同时滋养照墟玦里的大能（隐藏陷阱）
`

**剧情主线 2 是剧情主线 1 的副产物，但反过来定义了剧情主线 1 的结局**：
- 没有信仰功德 → 高调普渡只是空架子，撑不起对抗宗门的实力
- 信仰功德是结构性的杠杆——它让"被宗门架住"从舆论层面升级到实力+名声+修行三层联动
- 没有信仰功德 → 正式逐出只是名声损失；有信仰功德 → 正式逐出是名声+功德开源+实力增长源泉的三重打击

## 五、现有大纲章节的前期处理

**现有大纲章节内不启动正式逐出线，但必须提前铺出三类结构种子。**

这里的“前期”不死卡 100 章，可按正文节奏适当增减。核心不是章节号，而是主角尚未拥有足够实力、名气、资源和民间基础之前，不能让青玄宗中高层把“顾生没死”和“当年假死脱身”拼到一起。

前期原则：
- 不写追授逐出补丁
- 可以有宗门体系、中层封锁、大势力和高层代理人的互动，但**不能让青玄宗中高层确认顾生假死未死**
- 前期追查只能追查“泄密者”“暗中操盘者”“看见真相的人”的能力痕迹，不能锁定“当年死掉的顾生还活着”
- 不让顾生高调以青玄宗身份行事
- 不启动“青玄·救苦天神·顾生”神号线
- 可以出现“救苦天神”的民间雏形，但不正式解释功德机制

原因很简单：正式逐出线建立在主角已有一定实力之后。前期如果假死被青玄宗中高层识破，主角没有足够实力、名气、资源和民间基础去反向架住宗门，逻辑上会被直接杀掉，小说就不用继续写了。

### 5.1 前期护栏：高层互动可以有，身份确认不能有

| 维度 | 可以写 | 禁止写 |
|---|---|---|
| 宗门体系 | 青玄宗的附属势力、地方执行网、旧案痕迹、秦长老留下的制度阴影 | 秦长老本人确认“顾生没死” |
| 高层阴谋 | 金丹/元婴级幕后操盘、天玄圣地外围执行者、凡人压制网 | 幕后高层把线索锁定到“青玄宗杂役顾生” |
| 追查压力 | 追查“泄密者”“暗中操盘者”“异常看见者” | 追查“当年假死逃脱的顾生” |
| 顾生身份 | 顾大夫、无名救苦人、江湖模糊传闻 | 青玄宗顾生、青玄宗弟子身份公开行善 |

前期的核心写法是：敌人知道“有人在看”，但不知道“那个人就是顾生”；青玄宗知道当年有旧案裂缝，但还不能把裂缝拼成顾生活着的结论。

### 5.2 前期必埋：救苦救难行为

前期不能等到正式逐出线才突然“普渡众生”。顾生在现有大纲章节里就要开始做救苦救难的事，但动机仍然是“活下去/护住眼前人/处理眼前危机”，不是主动经营神号。

可用事件类型：

| 类型 | 事件样例 | 写作作用 |
|---|---|---|
| 灾害救村 | 山洪暴发，顾生借“看见”发现河道灵气堵点，改水道救下村庄 | 建立“救苦”实绩，且不靠战力装神 |
| 瘟疫救城 | 瘟疫爆发，顾生用凡间医术定规矩，用小神迹取得信任，让百姓隔离、净水、焚秽、分药 | 保留医生底色，同时用“神迹”解决凡人不信的问题 |
| 邪祟救民 | 有恶鬼、妖物或披皮卧底吞人，顾生不明说真相，借庙会、猎户、乡老之手除掉 | 和“看破不能说破”主线咬合 |
| 饥荒救急 | 粮仓被地方豪强/妖物控制，顾生布局让粮仓“自己暴露”，逼地方势力开仓 | 建立民心，不写成圣母施舍 |
| 水井净秽 | 村中井水被阴物污染，顾生用阵法破绽和药理配合，做成凡人看得懂的“净井仪式” | 形成可传播的民俗动作 |
| 孩童还魂 | 被妖物夺魂的孩子救回一半，顾生承认救不全，只保住命 | 保持代价，不让神迹万能 |

这些事件的传播结果不是立刻大规模封神，而是少量凡人开始私下供奉：
- 无名牌位
- 小木像
- “救苦人”纸符
- “救苦天神”四字的土名
- 村口小龛

顾生本人前期可以不知情，或知道后选择压下、不认、不解释。这样既埋“救苦天神”，又不让他提前变成高调宗教领袖。

### 5.3 前期必埋：借神名传播的第三方势力

单靠顾生一个人的善举，影响力和香火都有限。前期必须出现另一股势力，察觉“救苦天神”名号背后的好处，并主动帮助传播。

推荐方向：与顾生有过交集、偏向善意但不完全干净的山精野怪、小土地、河伯残灵、庙祝残魂、草木精灵一类存在。

它们的逻辑：
- 它们发现百姓供奉“救苦天神”后，庙里多了一种温热、清明、可滋养灵性的东西
- 它们不知道完整功德机制，只知道这东西有好处
- 它们借“救苦天神座下护法”的名义私设道场
- 它们收贡品、借香火修行，也真的替百姓办事
- 它们越有求必应，“救苦天神”的名号越容易宗教式传播

这股势力的戏剧价值：
1. **放大影响力**：顾生救一个村，它们能把“救苦天神”的规矩传到十个村
2. **制造灰度**：它们有私心，吃贡品、蹭香火，但不纯恶，确实护民
3. **制造后期可用组织基础**：后期宗门识破顾生假死后，顾生可以直接让这些教众/护法把“救苦天神”改称为“青玄·救苦天神·顾生”
4. **制造反噬风险**：神名被第三方经营后，不完全受顾生控制，可能出现假护法、假庙祝、敛财者、借名害人的支线

前期传播链条可以这样走：

`
顾生救一地 → 百姓立无名小龛 → 山精野怪发现香火好处
→ 自称“救苦天神座下护法” → 替百姓解决小灾小病小邪
→ 百姓更信“救苦天神” → 神名从地方土称变成区域传闻
`

### 5.4 前期种子清单

| 种子 | 作用 | 强度 |
|---|---|---|
| 救苦行为种子 | 主角救灾、救疫、救村、净井、除邪，但动机仍是处理眼前危机 | 每个大弧至少 1 次 |
| 信仰体感种子 | 主角救人后偶尔感觉到“一种说不清的温暖压住了深看带来的寒意”，他不知道这是什么，读者也不解释 | 出现 2-3 次即可 |
| 被立庙种子 | 苍梧或万家城某个被救活的村子自发立了无名牌位/小龛，主角某次路过看见愣住 | 至少一次 |
| 神名雏形种子 | “救苦人”“救苦先生”“救苦天神”等称呼从凡人口中自然长出来 | 先土后正，逐步统一 |
| 护法传播种子 | 山精野怪借“救苦天神座下护法”名义私设小道场，收贡品也办实事 | Arc 3-5 可启动 |
| 江湖传闻种子 | 前期出现“北边有个救苦人/救苦天神”的模糊传闻，指向不明，不能指向顾生本人 | 偶尔提一句 |
| 大能暗示种子 | Arc 4-5 大能偶尔说“他们看不见你身上的某种东西在挡”类暧昧话，主角不解，大能也不展开 | 一两句话级 |

前期这些种子必须服务于现有阴谋主线，不能喧宾夺主。正式功德机制、万民之主含义、信仰滋养照墟玦的真相，仍留到后期揭开。
