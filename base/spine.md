## 一、一句话内核（pitch）

一个现代医生穿越成"废灵根"，被踹下悬崖、濒死时抓住一块名为**照墟玦**的古物——它让他**看见所有人看不见的真相**：阵法的破绽、伪装者的本相、**别人对他的算计**。

但他每多看一分真相，就多一分被某种**未知存在**察觉、抹杀的危险。**看破，却不能说破；知道，却要装不知道。** 一个废灵根，夹在"看得见的阴谋"和"看不见的监视"之间，步步为营，憋着翻盘。

**爽感来源**：信息差碾压——他永远比所有人多知道一件事；权谋式智力爽——看破布局、将计就计、反杀算计者。
**核心张力**：看破≠能赢。他实力有限，看见了也只能忍着、装着、等着，在夹缝里一寸一寸往上爬。

## 二、金手指（详见 ../world/01-古物与金手指.md）

- **照墟玦**：坠崖时抓住的一截黑东西，钻入掌心，共生不可去。前期主角不知道此名，只当它是古物；内有一位**被封印大能**的残魂（详见 ../world/02-被封印大能.md）。
- **三重视界**：①运行规则（灵气/阵法/功法）②被掩盖的真相（伪装/篡改）③人心阴谋（对己算计）。随成长逐级解锁。
- **代价**：看见=暴露。深看会招来"未知存在"的清理（详见 ../world/03-底层法则.md）。
- **不给战斗力**。强在"看得清"，不在"走得和别人不一样"。主角走常规修炼。

## 三、主角顾生（去圣人光环 + 夹缝求生型权谋主角）

详见 ../characters/顾生.md。此处只列脊柱级要点：

- **保留**：穿越医生身份（**医术严格降级为凡间副业**，绝不靠它降维修仙界）、五灵根废灵根、"我只是个大夫"口头禅。
- **核心性格**：**夹缝求生的权谋型**。看破不说破是他的生存本能。冷静、克制、算计、能忍，但底色是善良——只是这份善良永远要给"活下去/护住在乎的人"让路。
- **主线欲望**：**活下去，并且搞清楚——照墟玦是什么，它为什么选中我，这世界的真相到底是什么，以及……我到底能不能，不被它（照墟玦里那个东西）和它们（未知存在）一起，吃掉。**
  - 这是**私人化的、求生驱动的**欲望，不是"拯救苍生"。拯救是路上撞见的、被迫承担的副产物。
- **人物弧光**：从"只想活下去的利己者" → "被迫看清越来越多真相、卷入越来越深的棋局、越来越无法回头" → 最终面对"我也是棋子吗"的存在性危机。
- **弱点（戏剧发动机）**：
  1. **穿越者的傲慢**——总觉得比这世界聪明（多数时候对），这让他**低估本地人的恶意与算计**，反复吃亏。
  2. **多疑到孤立**——因为"看破不能说破"，他谁都不敢全信（连照墟玦里的大能都不能信），越来越孤独。
  3. **医者的强迫症**——他戒不掉"救人"的本能（医生身份不是降维工具，是性格弱点）。这会被敌人利用，也会让他一次次冒险。

## 四、三层钩子（前段的三次"打脸级"反转）

网文定律：读者每翻一层，必须有一次认知地震+实力逆转。**新三层钩子，全部围绕"看见的真相层层深入 + 暴露威胁递增"。**

> 章号为七弧重排后的相对示意（详见 §六）：钩子1在 Arc1，钩子2在 Arc4，钩子3在 Arc7。

### 第1层：照墟玦让他"看见"，而"看见"是危险的（揭晓：Arc1，约 ch7-10）
- **钩子点**：顾生发现照墟玦让他看见别人看不见的东西（先是模糊的灵气流向，后是阵法/功法的破绽；此时他未必知道其名）。他用这个能力，在小事上**反杀**了算计他的人（第一次爽点）。
- **打脸**：一个废灵根，凭什么看穿天灵根都看不穿的阵法/功法？凭什么预判别人的算计？——因为他**真的看见了**。
- **代价炸点**：他第一次"深看"，换来一阵**被注视的寒意**。他以为是错觉。直到某次深看后，**恰好**有人来追查"泄密"——他第一次意识到，**看见，是要付出代价的**。
- **这一层建立的悬念**：古物是什么？它为什么让我看见？那阵寒意……是谁？

### 第2层：他看见的"真相"，触到了世界的中层封锁（揭晓：Arc4，约 ch57-62）
- **钩子点**：随着能力加深（第二重视界初现），顾生看见——**功法是被阉割过的**、**某些历史是篡改的**、**某些"同门"是披着人皮的妖/卧底**。他撞破了一个具体的、牵涉宗门高层的**阴谋**（详细阴谋事件见大纲）。
- **打脸**：他**看破了整个阴谋**，但不能说破（说了=暴露+没人信+害人）。他只能**将计就计**，用自己的方式，在不暴露"我看见了"的前提下，**瓦解阴谋、反杀幕后**。这是全书第一次大型权谋爽点。
- **代价炸点**：深看中层真相，引来**中度暴露**——某个势力**恰好**开始追查"泄密者"，顾生成了嫌疑对象。他必须在**应对看得见的追杀**的同时，**提防看不见的监视**。
- **这一层建立的悬念**：功法为什么被阉割？谁篡改了历史？那股追查"泄密"的力量，到底是谁？

### 第3层：他看见的，是世界的终极真相（揭晓：Arc7，约 ch126-139）
- **钩子点**：第三重视界加深 + 大能接近清醒，顾生看见——**世界的秩序是被设定并维持的**，**有一类"未知存在"专司清除窥探者**，而**他自己从一开始就在大能的棋局里**（捡到照墟玦不是巧合）。
- **打脸**：全书最大的反转——**主角的"金手指"本身是陷阱**。照墟玦帮他看见真相，是为了**把他卷入大能的复仇棋局**；而每一次看见，都在**加速他被未知存在锁定**。他被夹在两股力量之间：大能要利用他搅动秩序，未知存在要清除他这个窥探者。
- **代价炸点**：他亲眼目睹一次**未知存在的"清理"**——某个知道太多的人，被从所有人的认知里抹去，只留顾生一个人记得。**那一刻他明白，自己玩的是什么级别的火。**
- **前段收尾**：顾生看清了棋局的全貌（至少是前段能看清的部分）。他面临选择——**继续当大能的棋子（获得更多真相+力量，但离死更近），还是想办法摆脱（失去金手指，但也许能活）**。**不断在"他做决定之前"——而是断在"他第一次主动选择深看一个他明知会暴露的终极真相，为了……"**（具体留作前段收尾钩子，见大纲）。

## 五、节点（代价兑现的高潮，替代旧的A/B/C）

> 金手指的"刺"必须真扎进去、留疤、改走向。

### 节点①（约 ch12-15）：第一次为"看见"付出代价
- 顾生用深看反杀了一个算计他的人（第一次大爽点），但那次深看**引来了第一次实质性的暴露后果**——某个势力开始调查"泄密"，顾生险些被牵连，**他第一次真正恐惧**。
- **代价**：为了脱身，他不得不**牺牲/放弃**一样他本想保住的东西（一个机会/一个想保护的人的信任/一段本可澄清的关系）。**打脸与代价同章：他赢了那个人，却输了别的。**

### 节点②（Arc4，约 ch72）：看破阴谋却不能说破的极限
- 顾生看破了一个牵涉他身边人的大阴谋（比如某人要害方伯/苏瑶/苍梧镇），但**说破=暴露+没人信+可能害更多人**。他只能**独自扛着这个真相**，用一个不暴露"我看见了"的方式去化解。
- **代价**：化解过程中，**有人死了**（一个他本想救的人），因为他的方式受限（不能用"看见"的完整信息，只能装作偶然发现）。**他第一次体会到"看破却无力"的痛**——比看不见更痛。

### 节点③（Arc7，约 ch138-139）：主动选择深看终极真相
- 顾生明知深看终极真相=几乎必死（未知存在的清理），但他**为了护住所有人/为了打破棋局，主动选择深看**。
- **代价**：他看见了，也**被锁定了**。前段收在他"明知接下来会被清理、却已无路可退"的状态——带着他看见的终极真相，独自面对即将到来的"清理"。
- **这一刀全部由主角自己承担**，不转嫁给任何人（铁律：代价只能主角扛）。

## 六、前段结构（七弧线，双明线交替主导）

> 节奏框架升级为**七弧交替**：阴谋线（冷）与妖兽点化线（暖）**逐弧交替主导**。阴谋弧的核心事件全部是"阴谋故事"（看破算计但实力有限，看破不能说破，极限夹缝求生）；妖兽弧（Arc3 点化 / Arc5 香火）暖 + 萌 + 喜剧，但各保留一条细阴谋暗流。

> **双明线框架 + 四条前期护栏（详见 outline/总纲.md 顶部「双明线结构总览」+「第二明线」专节 +「前期护栏」）**：
> 1. **阴谋线（冷）与妖兽点化线（暖）交替主导**——本书是**双明线**结构，不是"主线 + 副线"。阴谋弧 Arc1/2/4/6/7；妖兽弧 Arc3/5。两线表面各走各的，到 **Arc7 终极真相处合一**（揭破"信仰一直在喂照墟玦"——暖线冷线从头同源，钩子3"金手指即陷阱"的支点）。是 后期「公开逐出 + 万民功德」主线（见 plan/逐出宗门-与-万民功德-双线方案.md）的前期胚胎。
> 2. **命名规约**：正文一律称**妖兽**，不用"山精野怪/小土地/庙祝残魂/精怪"等词。妖兽和人一样是这世界的生灵、一样分好坏，差别只在灵智高低/能否化形/善恶。主角杀恶妖（如 Arc2 卧底）、点化善妖，与"杀坏人、帮好人"同理，不是双标。
> 3. **假死识破是前段之后的后置节点**——前期绝不让青玄宗中高层确认"假死的顾生还活着"。前期追查只追"异常看见者/泄密者"的能力痕迹，锁不到人。原因：前期主角无破局资本，被确认=逻辑性秒杀。
> 4. **章节弹性**：第二明线升格 + 独占两条主导弧后，前段从约 100 章自然延展到约 **120-150 章**。下列七弧的章号是**相对示意**，不是死限。三层钩子/节点/书名兑现/后期主线**同比例后延**：钩子1/节点①在 Arc1，钩子2/节点②在 Arc4，钩子3/节点③在 Arc7。暗线（信仰喂照墟玦）前期只埋不揭、Arc7 揭破。

### Arc 1：坠崖与眼（ch1-15，阴谋主导）—— 金手指觉醒 + 第一次代价
- **核心阴谋**：赵玄机为什么踹顾生下崖？不是随手欺负——背后有个**针对"某种人"的清除行动**（顾生这种"差一点就要觉醒/被某东西盯上"的废灵根，被定期"处理"）。顾生借照墟玦看破这一点，但**不能说破**（说破=坐实他"被盯上"=更快被处理）。
- **打脸高潮**：顾生用看见的信息，**将计就计**，反杀/反制了追杀他的人，第一次尝到"信息差碾压"的爽。
- **代价**（节点①）：反杀的代价是第一次暴露后果，他险些被牵连，不得不放弃某样东西脱身。
- **弧尾**：顾生被迫离开青玄宗（被逐/逃），带着古物和"这世界不对劲"的认知，进入凡间。

### Arc 2：蝼蚁的眼（~ch16-30，阴谋主导）—— 凡间扎根 + 第二重初现
- **核心阴谋**：苍梧镇/万家城不是世外桃源。镇上有个**披着凡人皮的卧底/妖物**（顾生用第二重视界看见本相），它在执行一个**针对凡人的长期阴谋**（收集某物/监视某人/养蛊）。顾生看破了，但**他一个废灵根，说破没人信，动手又打不过**。
- **打脸高潮**：顾生用"看破不说破"的方式——**装作偶然、借刀、布局**——在不暴露自己能力的前提下，**揭穿/除掉了那个卧底**（坏妖，杀之有理），保住苍梧镇。
- **弧尾**：除掉一个，牵出更大的网。苍梧镇的危机不是孤立的，背后有更大的势力。**第二明线萌芽**：一对灵智高、会化形的善良妖兽（蠢萌妖父子）初遇顾生——小妖奶凶护食，顾生没舍得杀；妖父在妖斗中垂危（求救线头引入 Arc3）。详见 outline/总纲.md「创世故事：蠢萌妖父子」。

### Arc 3：点化（新增，~ch31-50，妖兽主导）—— 第二明线萌芽 + 成形
- **本书第一条妖兽主导弧。** 基调暖 + 萌 + 喜剧，与 Arc1-2 的冷阴谋强对照，是读者"在乎主角"的弧。
- **主导线（妖兽）**：妖父求救 → 顾生医术救父 → 父子无处可去悄悄跟随 → 见证顾生救村民 → 分别 → 吃光供奉回不去 → 一拍即合冒充"救苦天神座下护法"，**第一护法道场诞生**（创世故事 3-9 步）。道场"有求必应"：驱鬼、除妖（降伏收作小弟）、妖法治病。
- **救苦实绩**：山洪改道/开仓救荒/净井救疫择一落地，"救苦人/救苦天神"民间土称出现（先土，不指向青玄宗顾生）。
- **暗流（细阴谋）**：顾生躲青玄宗清除余波，撞见一条**凡间盘剥/猎杀阴谋**的边缘——救苦救难是接近现场的掩护。这条线不解，牵向 Arc4。
- **弧尾**：第一护法道场站稳，土名流传；顾生察觉这名号已不受控制（失控苗头，留 Arc5），那条凡间阴谋的线头把他拽向宗门高层大棋局。

### Arc 4：棋子（~ch51-72，阴谋主导）—— 钩子2炸 + 大型权谋战
- **核心阴谋**：一个牵涉**宗门体系/大势力**的阴谋浮出水面（功法阉割链/历史篡改/凡人压制的执行网，接 Arc3 暗流那条凡间线）。顾生**看破了整个阴谋全貌**（第三重视界初现），但这是**最大的"看破不能说破"**——幕后是金丹甚至元婴级的存在，说破=秒死。可有青玄宗附属势力、地方执行网、天玄圣地外围执行者和秦长老旧案痕迹，但不能让青玄宗中高层确认顾生假死未死。
- **打脸高潮**：顾生用全书至此最大的一次**权谋操作**——**连环布局、借多方的力、伪装成各方博弈的自然结果**——瓦解阴谋，让幕后互相残杀，自己全身而退。
- **暗流（妖兽线）**：第一护法道场已成形。本弧顾生**第一次把护法网当工具用**——借妖护法在凡间的耳目传声、打探、掩护布局，但不公开认领神名。
- **代价**（节点②）：瓦解过程中，有他想救的人死了（方伯？或其他人），因为他的方式受限。第一次体会到"看破却无力"；被救者与死者家属对"救苦天神"的信任出现分裂。
- **弧尾**：阴谋瓦解，但顾生**能力痕迹暴露**——某高层意识到"有人在暗中看破并操纵一切"，开始追查"泄密者/暗中操盘者/异常看见者"。追查不能确认"顾生活着"。

### Arc 5：香火（新增，~ch73-92，妖兽主导）—— 第二明线扩张 + 失控
- **本书第二条妖兽主导弧。** 基调暖中带乱：喜剧（更多蠢萌妖来投）与失控（投机者/恶妖照抄作恶）交织。
- **主导线（妖兽）**：护法网扩张（混不下去的妖陆续来投，每只一个小点化故事）→ 失控（"冒充护法能活"的路被投机妖/恶妖照抄，假护法、借名敛财、恶妖混入害人）。原始妖父子管不住，顾生不得不**暗中收拾**这个用他都不敢认领的神名作恶的烂摊子。
- **暗流（细阴谋）**：Arc4 权谋战后追查"异常看见者"逼近。护法网失控**恰好制造更多"异常痕迹"**，追查顺着痕迹逼近——顾生必须**亲手掐断快要被拼上的环节**（销毁痕迹、误导方向、制造假指向）。绝不让线索拼成"假死的顾生还活着"。看破不说破在此升级成"看破不能留痕"。
- **弧尾**：收拾住一部分失控，但顾生意识到这名号已成独立变量，再也按不住；追查逼近迫使他更深布局（引向 Arc6 大能博弈）。

### Arc 6：被注视的眼（~ch93-115，阴谋主导）—— 暴露升级 + 大能博弈
- **核心阴谋**：追查升级为**中度暴露**（"恰好"的追查与深看时间线高度重合）+ 照墟玦里大能开始**提条件**（要顾生去某封印地/找某物）。顾生**两面受压**——外面被追，里面被大能引导。他发现大能**给的信息不全可靠**，是在**引导**他。
  - **追查张力校准**：追的是"能力痕迹"，不是顾生本人。本弧惊险**不是肉身追杀逃命**，而是"那条线快要连起来了"——顾生必须**亲手掐断快要被拼上的环节**，绝不让中高层确认假死的顾生还活着（后期死局节点）。
- **暗流（妖兽线）**：Arc5 收拾后的护法网，本弧成为顾生的**撤离 / 传讯 / 情报基础**。大能可暧昧点出香火/民心像一层挡风的暖雾，但不解释机制（**信仰喂照墟玦**暗线第一次明确暗示）。
- **打脸高潮**：顾生**反过来算计大能**——假装顺从，实际利用大能给的部分信息，**既完成自己的目的，又没完全掉进棋局**。第一次对"金手指"反客为主。
- **弧尾**：大能半恼半欣赏，透露"你捡到照墟玦不是巧合"。顾生进入**谁都不能信**的最孤立状态。

### Arc 7：真相与火（~ch116-140，阴谋主导，两线合一）—— 钩子3炸 + 主动赴险
- **核心阴谋**：终极真相浮现——秩序是被设定的，未知存在专司清理，顾生一直在它们的视野边缘。大能的真实目的也清晰了（复仇/搅动秩序，且它不在乎顾生死活）。
- **两线合一（结构红利）**：终极真相揭示——护法教的香火功德一直在**喂养照墟玦里的大能**。那条暖洋洋的护法线和这条冷冰冰的阴谋线**从头就是同一条线**，顾生以为给自己套马甲，实则给自己挖坟（钩子3"金手指即陷阱"兑现）。
- **跨界（妖兽线收尾）**：护法教众越铺越广，连**人类散修**也开始加入，已是跨人妖之"教"——**万民之主胚胎成形**。
- **打脸高潮**：顾生**看清了整个棋局**——大能的棋、未知存在的网、世界秩序的锁。他不再被动，而是**主动选择深看一个终极真相**（节点③），明知会暴露，为了**找到打破棋局的那个关键点**。
- **前段收尾**：他看见了，也被锁定了。带着终极真相，独自面对即将到来的"清理"。**不是绝望，而是"我知道这一仗怎么打了"的冷峻**。读者带着最大悬念进入后期主线。

## 七、配角重设要点（详见 ../characters）

- **照墟玦里的大能**：不是工具，是**博弈方**。全书最重要的"看不见的对手+被迫的盟友"。详见 ../world/02-被封印大能.md。
- **赵玄机**：Arc1阴谋的执行者之一。不是单纯恶霸，是**秩序的基层看门狗**，知道部分中层真相，相信"清除那些人是为宗门好"。
- **苏瑶**：独立线。她有自己的秘密/目标（与凡人母亲之死有关，但**不再是"被抽真气"**，按新设定重做），与顾生**平行、偶尔交叉、彼此试探**。她对顾生的"秘密"有所察觉，顾生对她也"看破不能说破"——两人是**互相防备的同路人**。
- **方伯/方远**：凡间锚点。方伯的死（若保留）改为**被某个阴谋牵连**，顾生看破了却没能救（节点②的素材之一）。
- **秦长老**：青玄宗的秩序执行者。比旧版更立体——他**知道中层真相、选择维护秩序**，是顾生哲学上的镜像（都看见真相，选了相反的路）。
- **新反派类型**：不是"力量碾压型"，而是**算计型/伪装型**——顾生用"看见"识破他们，用权谋反杀他们。每个反派都是一个阴谋故事的核心。
