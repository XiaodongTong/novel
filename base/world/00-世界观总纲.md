## 一、一句话世界

一个**真相被层层掩盖、说真话的人会被抹掉**的世界。

表面上，这是一个标准的修仙界——宗门林立、境界森严、凡人如蚁。但每一层表象之下，都藏着更深的、不能让人知道的东西。**谁看见了不该看见的，谁就会消失。**

主角捡到一块名为**照墟玦**的古物，能让他"看见真相"——等于一只脚，踩进了"会被抹掉"的名单。

## 二、世界表层（所有人知道的部分）

这是普罗大众和普通修士认知里的世界：

- **修炼体系**：炼气 → 筑基 → 金丹 → 元婴 → 化神（更高境界只在传说中）。修炼靠感应天地灵气、引气入体、淬炼经脉。这是万年来的常识，没人怀疑。
- **灵根**：决定修炼资质。天灵根最强，五灵根最弱（"废灵根"）。灵根高低是天生的，不可改变。
- **宗门**：修仙界的权力实体。大宗门（天玄圣地一脉）统辖区域，小宗门依附。宗门收弟子、传功法、镇守一方。
- **凡人**：没有灵根、不能修炼的普通人，是修仙界的基石与供养者。修士高高在上，视凡人如蝼蚁。
- **妖兽**：表层认知里，妖兽只是"野外的威胁，凡人和低阶修士的死敌"——见之即杀。**但这是偏见**（真相见下「妖兽真相」）。

**这一层是"合理"的、自洽的、没什么问题的——只要你不去追问"为什么"。**

### 妖兽真相（第二明线赖以成立的设定铁律）

> 此条是「妖兽点化 → 护法教 → 万民胚胎」第二明线的设定根基，正文据此创作，登记于此（铁律：新机制先登记）。

- **妖兽和人一样，都是这世界的生灵，一样要生存，一样分好坏。** 见之即杀的偏见，正是表层秩序"把人/妖分等、对立"的产物之一。
- 妖兽彼此的差别，只在三条连续轴上：**灵智高低 / 能否化形 / 善恶**。高灵智、本性善、能化形的妖，与善良的人无异。
- **点化**：刘波遇到灵智高、本性善的妖（如蠢萌妖父子），因现代人灵魂"没舍得杀"而放过、甚至相救；妖被打动后短暂追随，见证他救人受香火，分别后自悟"冒充恩人（救苦天神座下护法）能活得不错"，遂自立护法道场。**"点化"是被打动、自封，不是签契约收编。**
- 因此**主角杀恶妖（如卧底妖物）、点化善妖，与"杀坏人、帮好人"同理，不是双标**。本书真正的恶，是看不见的秩序，不是妖、也不是凡人。
- **命名规约**：正文一律称**妖兽**，不用"山精野怪/小土地/庙祝残魂/精怪"等词（那些只是讨论用语）。

## 三、世界中层（只有少数高层知道，泄露即死）

随着主角"看见"得越来越深，它会逐渐撞破表层，进入这一层：

- **功法是被"规范"过的**：各宗门公开传授的功法，并非天地自然之道，而是经过**统一删改、阉割**的版本。真正的、完整的功法，被高层垄断。普通修士修的，是"被允许修的部分"。这保证了高层对低层、修士对凡人的绝对压制。（细节由各宗门的具体阴谋承载，见大纲的阴谋事件。）
- **灵根并非纯天生**：灵根的"优劣"，部分是被人为干预的结果。某些血脉/传承被压制，某些被扶持。这不是阴谋，是**制度**——一种延续万年的、把人分等的制度。
- **历史是被篡改的**：修仙界"万年传承"的说法，是改写过的。真实的过去（上古发生了什么、某些大能为何陨落/被封印、某些功法为何失传）被系统性地抹除。现存典籍里，越古老的部分越不可信。
- **"规矩"的本质**：修仙界种种铁律（不得私授功法、不得越界、不得窥探天机），表面是秩序，实质是**封锁真相的手段**。违反这些规矩的人，不是"被惩罚"，而是"被消失"——连同他知道的真相一起。

**这一层是阴谋的温床。主角每一次"看见"这一层的某一块，就卷入一个具体的阴谋故事。**

## 四、世界终极层（全书最深秘密，极少数存在知晓）

这是古物里那位**被封印大能**陨落/被封印的根源，也是"看见=暴露"机制的核心：

- **世界的真相是被"设计/维持"的**：这个修仙世界的运转法则（灵气从何而来、境界如何划分、为何有人能修炼有人不能），并非天地自然，而是**被某种存在/某种机制设定并维持**的。
- **"未知存在"**：有一类存在（具体形态/性质是终极悬念，前期只表现为"感知到偷看者的危险"），它们**守护着这个被设定的秩序**。任何试图窥破秩序真相的"偷看者"，都会被它们察觉并清除。
- **被封印大能**：照墟玦里的那位，是上古**看破了秩序真相、试图改变它、最终被镇压**的存在。它没有死，被封印在照墟玦里。它把"看见真相"的能力，留给了捡到照墟玦的人——既是传承，也是**复仇的工具**、也是它**借主角之手重新搅动秩序**的棋。
- **代价的根源**：主角"看见真相"，本质上是在**触碰被封锁的秩序**。看得越深，越像在禁区的墙上凿洞——墙后面的"看守"会注意到。这就是"看见=暴露"的世界观根基。

**这一层是全书终极悬念。主角前100章只会触及它的边缘，真正揭开在更后期。**

## 五、势力格局

| 势力 | 表面 | 真实（中层/终极层） |
|---|---|---|
| **天玄圣地** | 修仙界至高圣地，万法之源，维护秩序 | 秩序的**执行者**与既得利益者。掌握最完整的功法与历史真相，镇压一切窥探者。是主角最大的、看不见的敌人。 |
| **大宗门（玄明宗等）** | 各区域统治者，传承功法 | 天玄圣地的**附庸**。执行"功法阉割""历史篡改"的中层执行者。每家都有自己的黑历史和阴谋。 |
| **万仙宗**（主角出身） | 一个普通的中等宗门 | 典型的"规矩执行者"。沈千秋这类高层，是秩序在基层的看门狗，知道部分中层真相；**同时也是夺根基禁术的源头**——他用清除体系养自己的根基（私利），详见 05-夺根基禁术.md。 |
| **血煞堂** | 邪修组织，圈养凡人 | 待重新定位：可能是秩序的**叛逃者**——他们窥见了部分真相，用扭曲的方式谋利；也可能是被秩序默许的"泄压阀"。具体见大纲。 |
| **凡人** | 蝼蚁、供养者 | 被秩序**系统性压制**的群体。他们的"不能修炼"是被设计的结果。真相公开=秩序崩塌。 |
| **未知存在** | 不存在（无人知晓） | 秩序的**终极守护者**。全书最大的威胁。前期只以"暴露后的危险"形式出现。 |

## 六、地理
- **万仙宗**：主角出身的宗门，故事起点。
- **万仙宗后山禁地（上古封印地）**：万仙宗后山一片被宗门列为禁地的区域，实为**一处上古封印地的边缘**。宗门只知道"祖训不得入"，不知封的是什么（实为上古被封印大能的遗骸/残片散落处，见 02-被封印大能.md）。禁地有上古禁制，擅入者死或失踪，宗门默认是"凶地"敬而远之。**这是 ch1 取材-逃亡-得古物的场景**：顾长缨的取材作业设在禁地边缘钻空子（禁地边缘禁制稀薄，能偷进偷出），刘波取材失败后逃入禁地深处——反派不敢深追（进禁地深处=触发上古禁制=暴露自己在搞禁术=宗门追查，对反派来说暴露禁术比丢一个药引更致命），只能在禁地边缘布锁魂阵等残片飘出来收。照墟玦就嵌在封印地深处缝隙的石壁里（本是封印大能的遗物残片，出处天然合理）。
- **沧溟三十六寨 → 万家城**：主角凡间游走扎根之地，凡人觉醒的火种。沧溟三十六寨是方圆数百里的边荒流民地带，三十六寨沿黑水河散布；Arc2 主角以云游道人身份游走其间。
- **天玄圣地**：修仙界中心，终极敌人的巢穴。
- **上古遗迹/封印地**：散落各处，藏着真相碎片，是大能苏醒的线索来源。万仙宗后山禁地是其中一处。

## 七、修炼体系（沿用境界名，微调内涵）

- 境界名不变：炼气/筑基/金丹/元婴/化神。
- **关键调整**：主角的修炼**不再依赖任何"特殊经脉/暗脉/中医降维"**。主角的修炼走的是**常规体系**，但因为照墟玦能让他"看见"功法/灵气/阵法的真实运行规则，他的修炼效率、识破能力远超同阶——这是**信息优势**，不是**体系外挂**。他强在"看得清"，不在"走的路和别人不一样"。
- 照墟玦本身**不直接给战斗力**。它给的是"看见"。战斗力靠主角自己在常规体系里修炼+利用看见的信息布局。

### 灰膜（秩序执行网在"深陷执行者"身上的可视标记）

- **是什么**：万仙宗等秩序执行体系内，**长期深度执行清除任务的人**（执行末端 → 核心执行者）眼底会浮现的**一层灰色膜**。**它是秩序执行网的"沉淀"，不是未知存在留下的痕迹**。
- **双层解释（v5.2 补充，详见 05-夺根基禁术.md §四）**：
  - 第一层：秩序执行网在"深陷执行者"身上的可视标记（本节原解释）。
  - 第二层：对**修夺根基术的人**（顾长缨、沈千秋；魏长宁作为现场作业者程度较浅），灰膜同时是**禁术的代价痕迹**——反哺越多，灰膜越深。两层同一种表象，叠加存在。
- **关键铁律**：**绝对不能与"未知存在"挂钩**——未知存在在 Arc7 之前**不可知、不可见**（见 03-底层法则 §二）。灰膜属于"中层秩序在执行者身上留下的可见印记"（含执行网沉淀 + 夺根基术代价两层），是**人 + 制度**层面的具象化，不是"超越人力的清理机制"的直接痕迹。
- **谁会有灰膜**：钱小六（被顾长缨卷进来）、魏长宁（顾长缨的执行末端）、顾长缨（核心执行者，灰膜最厚）——做得越深，灰膜越明显。
- **谁没有灰膜**：刘波（他是被清除对象，不是执行者）；鹿啸、鹿鸣、宋清漪母亲等凡人（与执行网无关）。
- **刘波能看见灰膜**（第三重视界·人心阴谋 + 中层真相层），但他看见的也只是"这些人有灰膜、这层膜来自秩序执行网"——他**不能通过灰膜看见"未知存在"**。灰膜对刘波来说是**识别清除体系成员**的标记，不是**看见更高层真相**的工具。
- **Arc7 之前的写作禁忌**：不要在任何正文里把灰膜和"主峰那个东西/未知存在/秩序终极守护者"直接关联。灰膜是"中层能看见的具象"——悬念必须留到 Arc7 才揭。

### 五灵根的全谱兼容性（夺根基术的最优药引）

- **是什么**：五灵根在常规修炼里是"废灵根"（五行散乱、效率极低），但在夺根基术里反而是**最优药引**——因为天灵根暗伤是"根基裂痕"，需要**全谱材料**修补；普通废灵根（二三灵根）残片五行偏废，补进天灵根裂痕会加重排斥，**唯有五灵根残片五行俱全，能和天灵根全谱兼容**。
- **"最废"与"最优"是同一枚硬币**：这具体兑现了中层真相"灵根优劣是被人为分等的"——所谓"废灵根"，只是常规修炼体系的偏见；在另一套体系（禁术）里它是上等货。**"废"不是天性，是分等的结果。**
- **主角的不可替换性**：五灵根本就极罕见（几代才出一个），"差一点觉醒"状态的五灵根残片活性最高。刘波是顾长缨攒多年才等到的最上等药引——错过他得再等不知多久。这是"为什么偏偏是刘波被定向猎杀"的根源（详见 05-夺根基禁术.md §二）。
- **与穿越者/古物解耦**：药引特异性纯粹来自五灵根体质，**与穿越者灵魂无关**。"为什么偏偏刘波捡到照墟玦"是另一条独立伏笔（G6 主角是棋子），不与药引特异性焊接，前期保持表层巧合。
- **关键铁律**：这是**中层真相的具体兑现**，但 Arc1 只埋具象证据（顾长缨对刘波的异常执着、取材现场的全谱收取痕迹），**不点破"全谱兼容"四个字**——名字和原理留到中后期某节点由刘波"看见"拼出。
