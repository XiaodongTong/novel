## 核心阴谋：青玄宗的"清除名单"
青玄宗（代表秩序的基层）有一份不成文的**清除名单**——那些"差一点就要出问题"的废灵根/边缘修士（指标：灵根异常、被某东西轻微注意、差一点觉醒某种感知）。赵玄机是执行者之一。踹顾生下崖，是一次例行清除。

顾生借照墟玦**看破**了这个名单的存在（第三重视界雏形——他看见赵玄机对某几个杂役的"特殊关注"模式、看见某次清除后的痕迹；此时他未必知道其名），但他**不能说破**——说破=坐实他"有问题"=立刻被重点清除。

## 章节推进
| 章 | 事件 | 主角主动决策/行为 |
|---|---|---|
| 1 | 被踹下崖→濒死抓住照墟玦（前期不知其名）→钻入掌心→视野变了→躲过补刀。**开篇即冲突即金手指。** 钩子：看见崖壁里流动的光 | 抓住照墟玦（求生本能）；装死躲过补刀者视线 |
| 2 | 回宗装没事。照墟玦偶尔让他"看见"模糊灵气流向。第一次在小事上用"看见"占到便宜（识破某个针对他的小算计） | 在被欺压时"无意"指出对方灵力走偏，让对方当场失态 |
| 3 | 第一次深看→**那阵寒意**出现（暴露机制种子）。顾生以为是错觉，但记住了 | 决定"下次深看前先想清值不值"（主动克制） |
| 4-5 | 古物能力渐显。顾生察觉赵玄机对"某几个杂役"的特殊关注模式（第三重视界雏形） | 主动开始**记录**赵玄机关注谁/不关注谁（行为级） |
| 6 | 卷入边缘：某个被赵玄机"关注"的杂役失踪了（被清除了）。顾生"看见"了清除的痕迹 | 决定**不声张**，但把那个杂役的遗物藏了一片（伏笔） |
| 7-10 | **钩子1半揭/全揭+第一次大爽点**：顾生确认照墟玦让他"看见"，并用它**反杀**了一个算计他的人（某个奉赵玄机之命来试探/处理他的人）。**看破不说破**的第一次完整实践 | 主动**设计一个"被试探"的局**，让对方先露马脚再反制 |
| 10 | **代价**：反杀那次深看，引来第一次实质性后果——有人开始调查"最近怪事"，顾生险些被牵连 | 主动**站出来做伪证人**，用看见的信息编"合理怀疑"误导追查方向 |
| 11-14 | **节点①**：反杀招来追查，顾生被迫铤而走险脱身。手段不干净（拿死者林小山做伪证、把灰膜未醒的王二麻当工具借旧封印反咬），事后他自己心里有数 | 决定**主动出手**而不是等待追查上门；以伪证+借刀的方式脱身 |
| 15 | **Arc1收尾**：顾生身份暴露/被逐/逃。带古物和"这世界在清除某种人"的认知，进入凡间 | 选择**主动逃**（不是被逐），且**主动留陷阱**给追踪者 |

## 实力推进（Arc1：屈辱期，八维全压制）

> 详见 [04-修炼成长.md](../world/04-修炼成长.md)。Arc1 是实力线的"蛰伏底色"——求生压制一切，**八维基本无进账**，但要把"为何无进账"写得让读者心疼，为 Arc2 起步打足情绪底。

### 境界起→终
- **起**：炼气一层
- **终**：炼气一层（境界不变，**经脉理顺、吸收效率从"吸十留一"压到"吸十留三"**——内功，外人不可见）

### 八维进账（极少）
| 维度 | Arc1 状态 | 来源 |
|---|---|---|
| **修为** | 炼气一（经脉理顺） | 古物理顺；杂役院月例下品灵石（极少）；药园丢弃边角灵草 |
| **功法** | 旁观宗门入门版 | 一年前刚入门即被分杂役，没机会上手；古物**第一次让他看穿"被允许修的部分"** |
| **法宝** | —— | 杂役无配发 |
| **攻击** | 凡间医学+体术 | 前世医生的身体记忆 |
| **防御** | 看见预判 + 装傻扮无害 | 古物觉醒后第一道护身术 |
| **逃跑** | **装死、装傻、扮无害**（ch1 抓崖的求生本能即此种） | 求生压力下天然生出 |
| **幻术** | —— | —— |
| **阵法** | **看穿**阵法结构（古物能力）但**不能布、不能破** | ch6-10 看穿赵玄机布的"清除"暗阵 |

### 第一次实战（ch7-10 反杀奉命试探者）
- **对手境界**：炼气一（同阶；但属外门杂役里的"狠角色"）
- **越阶情况**：不越阶，**同阶碾压**——读者第一次看到"信息差能反杀同阶"
- **手段**：看穿对方布的小陷阱→反向布陷阱→借第三方手让对方先动手→自卫名义反杀
- **战利品**：对方身上几块下品灵石、一张低阶符箓（**Arc1 唯一的"战利品"——但他被迫上交了大部分作为"伪证"道具**）

### 屈辱期的戏剧化
- **ch12-14 节点①**：代价由"反杀招来追查 + 被迫提前离宗 + 脱身手段不干净（伪证、借刀）"承担，不再额外要求他"放弃某件实物"。读者要看到的是：他赢了那个试探者，但赢得很狼狈，且被赶出了原本苟活的位置。
- **ch15 离宗瞬间**：写一笔顾生独自看着掌心黑纹，第一次升起"必须把实力提上来——修为、功法、法宝、法术，全要"的执念。这是 Arc2 实力线起步的情绪锚点。

### 写作硬指标
- 每3-5章至少 1 次"修炼/看见/装无害"画面：盘膝/引气/看灵气流向/装废，**绝不空喊"他偷偷修炼"**。
- 章末钩子可以是"实力相关"：今夜引气有了新发现 / 攒下的灵石被人盯上了 / 看见赵玄机眼底灰膜在修炼时浮得更深 / 第一次看清一道入门符箓的真实结构。
