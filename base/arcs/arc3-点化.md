## 主导线（妖兽）：妖父子点化 → 第一护法道场
- 妖父求救 → 顾生医术救父 → 父子无处可去悄悄跟随 → 见证顾生救村民，也见证"顾大夫能救苦"的口碑、无名牌位、小龛和零散香火已在民间出现 → 分别 → 吃光供奉回不去 → 一拍即合冒充"救苦天神座下护法"，**第一护法道场诞生**（创世故事 3-9 步）。
- 道场"有求必应"：驱鬼、除妖（降伏后收作小弟）、用妖法治病。名号开始扩散，收贡品也真办事。
- **逻辑前提**：护法身份不是凭空成立，必须建立在 Arc2 后半到 Arc3 前半已经累积的救苦群众基础上；妖父子只是钻进了这个已有神名空位。

## 暗流（细阴谋）：躲余波 + 查一条凡间线
- 顾生在凡间站稳（万家城雏形 / 苏瑶线交叉）的同时，**躲青玄宗清除行动的余波**（Arc2 牵出的更大的网仍在缓慢逼近）。
- 撞见一条**凡间小阴谋**（地方势力/某宗附属对凡人的盘剥或猎杀），救苦救难常是接近这条阴谋现场的**掩护**。这条暗流不解，留给 Arc4 接续放大。

## Arc3要解决的设计问题
- **妖父子（第一护法）的具体设计**：种族/形态/名字；小妖"蠢萌+独特灵智"的具体表现（奶凶、护食、点子刁）；妖斗中妖父垂危的起因；顾生救父的细节；第一处护法道场在哪

### ✅ 妖父子设计决策（已定，见 characters/）
- **种族**：山獾（民间獾子，灵智高、能化人形）。理由：朴实的民间形象（与狐/蛇等"妖艳型"反着来）、护食本能天然匹配"奶凶护食"、父子气质对比鲜明。
- **命名**：獾吉（爹，图个吉利）+ 獾团（崽，圆团的团）。化形后自己起的，村野+笨拙。
- **人物档案**：见 `../../characters/獾吉.md` 与 `../../characters/獾团.md`。
- **獾团核心**：奶凶护食（藏野果、被撞见、露獾牙）+ 蠢萌（模仿大人走样、念错字）+ 点子刁（歪主意多，但常翻车）+ 模仿能力强。"一拍脑袋冒充护法"是他的主意——没有他，第一护法道不会诞生。
- **獾吉核心**：朴实笨拙 + 不善言辞 + 力气大 + 护子 + 老实人的底线。"做善良"和"做读书人"不一样——他只是跟着儿子拍脑袋，但他有自己的底线（不许护法道害人、不许欺负凡人）。
- **父子对比**：爹朴实笨拙被崽拽着走，崽精明歪点子但翻车。这种反差是 Arc3 暖的核心。

## 实力推进（Arc3：全书第一个境界突破大爽点——筑基！八维进入"实力跃升期"）

> 详见 [04-修炼成长.md](../world/04-修炼成长.md)。**Arc3 ch36 筑基突破是全书第一个境界突破大爽点**——读者从 Arc1 屈辱期一路忍到这里，要的就是这一刻。但**境界只破到筑基初期**，更大的实力跃升来自八维其他维度。

### 境界起→终
- **起**：炼气大圆满（Arc2 末）
- **终**：**筑基初期**（不破中期；筑基中期留给 Arc4）

### ch36 筑基突破章·四件套
- **触发**：救妖父过程中（创世故事 3-4 步），顾生第一次为了救"非人生物"调用医术 + 古物联用。妖父喷的妖力反向冲入顾生识海，让他**第一次看见"灵气可以走非人体设计的路径"**——五灵根原本就是"非人体设计的灵根类型"，这是钥匙。
- **资源消耗**：
  - Arc2 攒下的灵石**一次性烧光**（约 200 块下品 + 20 中品 + 部分上品）
  - 卧底功法残卷里"被改过的那一段"——顾生第一次启用未阉割版本（**Arc2 末埋的伏笔在此兑现**）
  - 苏瑶若此时在场，可能"恰好"留下一颗筑基丹（她在"投资"他）
- **看见辅助**：突破时古物让他看见识海里整片灵气海的"被设定的边界"——他看见了"凡人/低阶修士的天花板是被画上去的"。这是他第一次窥见**中层真相**（功法/灵根的人为设定），与第二重视界解锁同步。
- **情绪弧**：
  - 前 = 救妖父的医生本能 + 五灵根+杂役出身的自我怀疑（"我也能筑基？"）
  - 中 = 走火边缘 + 妖父用妖力反向稳住他识海 + 妖崽抱着他爹哭着喊"别让顾大夫死"——**暖线与实力线在突破时刻合一**
  - 后 = 第一次成为"筑基修士"，但他立刻警觉：筑基意味着浑身灵力气息变厚，他的"假死杂役"伪装更难维持。**实力上一阶 = 暴露风险也上一阶**

### Arc3 越阶战斗（关键展示，每弧硬指标）
- **ch46-48 第一次正面打筑基中期**：凡间小阴谋的执行者（建议设为一个落难散修，筑基中期，被某宗附属势力收买来盘剥凡人），顾生**正面对决**——用筑基初期的本身、加完整真功法的招式、加古物看见对方破绽、加新学的三角杀阵布场，**完整碾压一个筑基中期**。这是 Arc3 越阶战斗的硬指标兑现。
- **越阶手段**：四维叠加（真功法+看见+阵法+法器）让他"实战实力"=筑基中后期。

### 同阶碾压实写
- ch37-46 期间，顾生处理几个筑基初期对手（凡间小阴谋的中层），**碾压**——读者第一次直观看到"筑基初期顾生 vs 别的筑基初期=三秒一个"。

### 实力差展示
- ch48 后续——顾生**看见**那场小阴谋的真正幕后是金丹后期长老，但他完全不能动，只能记账。**让读者看见上限**——筑基修士面对金丹的天堑。这是 Arc4 阴谋大棋局的伏笔。

### 关键资源进账（Arc3 整弧）
- **ch36 突破后**：丹田扩张约 5 倍，灵气储量从"一杯水"升到"半桶水"
- **ch37-42 凡间救苦**：山民用采来的**野生灵草/低阶妖兽内丹**抵诊金（凡间不识货，对顾生是宝）
- **ch43-46 护法网汇集**：零散贡品里偶有筑基级灵物（百姓不知道是宝，妖父子也只懂吃），无意中堆到顾生那边
- **ch46-48 越阶战斗战利品**：筑基中期对手的储物袋——筑基级法宝 1 件（建议本命飞剑的胚胎，Arc4 完成炼化）+ 高阶功法残卷 + 中品灵石若干
- **未来伏笔**：Arc3 末顾生发现"护法网的贡品流向异常"——为 Arc4 大型权谋战和 Arc7 揭破"信仰喂照墟玦"埋点

### 戏份硬指标
- **ch36 突破章必须是大爽点章**——单章字数允许超 3000 上限，写满突破四件套（触发+资源+看见+情绪），是 Arc3 的支柱章。
- **筑基修士的"新感觉"**要在 ch37 起多次复现：飞行试探 / 灵识初现 / 法力厚度 / 一掌劈出有了筑基级威力——每一项都让读者看到"实力真的上来了"。
- **妖父子见证主角苦修**是 Arc3 暖线的核心镜头：妖父在旁默默护法、妖崽偷偷帮顾生擦汗递水，**实力线与妖兽线在情感上深度绑定**。
- **每弧"实力差展示"硬指标**：ch48 看见金丹后期幕后的那一笔必写——防止主角看起来无敌。
