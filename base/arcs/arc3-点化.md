## 主导线（妖兽）：妖父子点化 → 第一护法道场
- 妖父求救 → 刘波医术救父 → 父子无处可去悄悄跟随 → 见证刘波救村民，也见证"顾大夫能救苦"的口碑、无名牌位、小龛和零散香火已在民间出现 → 分别 → 吃光供奉回不去 → 一拍即合冒充"救苦天神座下护法"，**第一护法道场诞生**（创世故事 3-9 步）。
- 道场"有求必应"：驱鬼、除妖（降伏后收作小弟）、用妖法治病。
- **逻辑前提**：护法身份必须建立在 Arc2 后半到 Arc3 前半已经累积的救苦群众基础上；妖父子只是钻进了已有神名空位。

## 暗流（细阴谋）：躲余波 + 查一条凡间线
- 刘波在凡间站稳（万家城雏形 / 宋清漪线交叉）的同时，**躲万仙宗清除行动的余波**。
- 撞见一条**凡间小阴谋**（地方势力对凡人的盘剥/猎杀），救苦救难常是接近这条阴谋现场的**掩护**。留 Arc4 接续放大。

## Arc3 设计决策（已定，见 characters/）

### 妖父子
- **山獾**（民间獾子，灵智高、能化人形）。朴实民间形象（与狐/蛇等"妖艳型"反着来）、护食本能匹配"奶凶护食"、父子气质对比鲜明。
- **獾厚**（爹，图个吉利）+ **团子**（崽，圆团的团）。化形后自取，村野+笨拙。
- **团子核心**：奶凶护食（藏野果、被撞见、露獾牙）+ 蠢萌（模仿大人走样、念错字）+ 点子刁（歪主意多但常翻车）。"一拍脑袋冒充护法"是他的主意。
- **獾厚核心**：朴实笨拙 + 力气大 + 护子 + 老实人的底线（不许护法道害人、不许欺负凡人）。
- **父子对比**：爹被崽拽着走，崽精明歪点子但翻车——Arc3 暖的核心。
- 详见 `../../characters/獾厚.md`、`../../characters/团子.md`。

### 净井救疫关键人物
- **鹿小满**：8 岁凡人女孩，净井救疫关键孩子。其母陈嫂立无名牌位，是 Arc5+ 护法道场群众基础。
- 详见 `../../characters/鹿小满.md`。

## 实力推进重点

### 境界
- 起：炼气大圆满　终：**筑基初期**（不破中期，筑基中期留 Arc4）

### 关键资源进账
- **ch36 突破**：Arc2 攒下的下品 200+ / 中品 20+ / 部分上品**一次性烧光**
- ch37-42 凡间救苦：山民用野生灵草/低阶妖兽内丹抵诊金
- ch43-46 护法网汇集：贡品偶含筑基级灵物（百姓不识货，妖父子也只懂吃，无意中堆到刘波那边）
- ch47-48 越阶战利品：筑基中期对手储物袋——**筑基级法器 1 件**（建议**本命飞剑胚胎**，Arc4 完成炼化）+ 高阶功法残卷 + 中品灵石若干
- **Arc3 末伏笔**：发现"护法网贡品流向异常"——为 Arc4 权谋战和 Arc7 揭破"信仰喂照墟玦"埋点

### ch36 筑基突破·四件套（**Arc3 顶点章·单章可超 3000 字**）
- **触发**：救妖父过程中第一次为"非人生物"调用医术+古物联用。妖父喷出妖力反向冲入识海，让他**第一次看见"灵气可以走非人体设计的路径"**——五灵根原本就是"非人体设计的灵根类型"，这是钥匙。
- **资源消耗**：
  - Arc2 攒下灵石一次性烧光
  - 卧底功法残卷"被改过的那段"——第一次启用未阉割版本（**Arc2 末伏笔兑现**）
  - 宋清漪若在场，可能"恰好"留下一颗筑基丹（她在"投资"他）
- **看见辅助**：古物让他看见识海里整片灵气海的"被设定的边界"——他**第一次窥见中层真相**（功法/灵根的人为设定），与第二重视界解锁同步。
- **情绪弧**：
  - 前 = 救妖父的医生本能 + 五灵根+杂役出身的自我怀疑（"我也能筑基？"）
  - 中 = 走火边缘 + 妖父用妖力反向稳住他识海 + 妖崽抱着他爹哭着喊"别让顾大夫死"——**暖线与实力线在突破时刻合一**
  - 后 = 第一次成为"筑基修士"，但他立刻警觉：筑基意味着浑身灵力气息变厚，"假死杂役"伪装更难维持。**实力上一阶 = 暴露风险也上一阶**

### Arc3 越阶战斗（ch47-48 正面打筑基中期）
- 对手：凡间小阴谋执行者（建议设为落难散修，筑基中期，被某宗附属势力收买盘剥凡人）
- 越阶情况：筑基初期 vs 筑基中期
- 手段：**四维叠加**——真功法+看见+三角杀阵+新拿到的筑基级法器，让实战实力=筑基中后期
- 这是 Arc3 越阶硬指标兑现，**正面碾压**（无需借刀）——与 Arc2 借刀型越阶形成对比

### 同阶碾压实写
- ch37-46 期间处理几个筑基初期对手（凡间小阴谋的中层）——**三秒一个**，读者第一次直观看到"筑基初期刘波 vs 别的筑基初期"。

### 与三线咬合
- **ch36 突破时刻**：妖父稳识海+妖崽哭喊救命，**暖线与实力线同帧**
- ch47-48 正面打筑基中期 = 实力线兑现 + 阴谋线（凡间小阴谋）撕开一角
- 护法网贡品流向异常 = 妖兽线副产物为后期权谋战和终极真相埋点
