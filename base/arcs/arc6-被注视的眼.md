# Arc 6：被注视的眼（~ch93-115，阴谋主导）

> 隶属 ../spine.md。冲突时以 ../spine.md + ../world 为准。

## 核心阴谋：外面追 + 里面引（大能博弈）
- **外面**：Arc5 的追查升级为**中度暴露**——"恰好"的追查与顾生的深看时间线高度重合。但追查对象仍是"能力痕迹"，绝不让中高层拼成"假死的顾生还活着"（后期死局节点）。
- **里面**：照墟玦里的大能开始**提条件**（要顾生去某封印地/找某物），并**选择性透露信息**引导顾生。顾生发现大能给的信息不全可靠。
- 本弧惊险**不是肉身追杀逃命**，而是顾生在"被追查的能力痕迹"与"大能的引导"两面受压下，**看破不能留痕**地周旋。

## 暗流（妖兽线）：护法网成撤离/传讯基础
- Arc5 收拾后的护法网，本弧成为顾生的**撤离 / 传讯 / 情报基础**——危急时妖护法网替他打掩护、传消息、转移焦点。

## 实力推进（Arc6：故意压境界，反算计大能偷上古真东西）

> 详见 [04-修炼成长.md](../world/04-修炼成长.md)。**Arc6 ch112 = 反算计大能·从棋局里偷东西**——但偷的不是境界（顾生主动压住筑基后期不破大圆满），而是**上古真功法+上古法宝+自创幻术**——这些远比一阶境界值钱。

### 境界起→终
- **起**：筑基后期（Arc5 末）
- **终**：**筑基后期·满**（瓶颈，**故意不破大圆满**）

### 为什么故意压境界？
- 顾生在 Arc6 看清了大能的"鱼饵"——大能想引他去某封印地，借机让他境界突破，把他更深绑进棋局。
- **顾生反其道**：境界压住不破，但**把封印地的真东西偷回来**——这样他既没"被借机突破"被大能控制，又拿到了大圆满+下一阶段需要的真材料。
- 这是 Arc7 一次性突破到筑基大圆满的伏笔。

### ch112 反算计大能·完整章设计
- **触发**：在封印地（大能引导）里，顾生看见上古留下的**未被秩序"规范"过的真功法/真灵气路径**。大能本来打算让他修一种"看起来强、实际把他更深绑进棋局"的功法，但顾生用第三重视界**看出了陷阱**，反过来挑了一条大能没想让他看见的路径。
- **反算计手法**：
  1. 假装按大能指示修"陷阱功法"——大能放心，开始引他走第二步
  2. **故意走错一步**（看似失误，实则故意——让大能以为他笨）
  3. 大能急了，亲自指点"正确路径"——顾生借此**看穿大能藏私的痕迹**
  4. **偷换概念**：他按大能指点走真正路径，但同时**偷走大能没指的那条上古真功法**（用古物在大能不防备时扫了一眼藏在另一处的玉简）
  5. 突破假装失败（境界不破），让大能以为他"还没到时候"——但其实他**故意压住，等真东西完全消化后再一并爆发**
- **大能反应**：**半恼半欣赏**——他没想到主角能反过来用他给的东西。"你比我想的有趣。" 博弈正式升级。
- **情绪弧**：
  - 前 = "我必须比大能更聪明" 的执念
  - 中 = 在大能精心设计的路径上故意走错一步 + 偷走大能没指的真东西
  - 后 = 境界没破但实力暗暗大涨。第一次**对金手指反客为主**——他从"被喂的"变成"偷喂自己的"。

### Arc6 越阶战斗·**ch113-114 战金丹中期**
- **对手**：追查"异常看见者"的金丹中期修士（某秩序执行势力的中层）
- **越阶情况**：**筑基后期**对**金丹中期**——两阶差距
- **手段**：七维叠加——本命飞剑（已炼化第二阶段）+ 上古真功法雏形 + 上古法宝防御 + 幻影分身（Arc5学的）+ "看见反用"型幻术（Arc6 新自创）+ 筑基级杀阵+看见破绽
- **结果**：**击杀**——但**耗尽上古防御阵+本命飞剑剑魂回炉一周+识海受损半月**。代价兑现。

### 同阶碾压实写
- ch96-110 期间，顾生处理几个筑基后期/大圆满对手——**碾压**（虽然他自己也是筑基后期，但八维领先太多）。

### 实力差展示
- ch101-108 大能展示自己被封印前的境界——**化神之上**。让读者明白：主角再强，**面对大能本尊（如果苏醒）仍是蝼蚁**。这是 Arc7 揭破"金手指即陷阱"的伏笔。

### 关键资源进账
- **封印地奇遇**（Arc6 最大资源池）：
  - 上古真功法 1 套（不完整，但比 Arc4 的更深一个层次）
  - 上古防御阵图 1 卷
  - 上古法宝 1-2 件（防御+瞬移类）
  - 上古丹方若干
  - 关键灵物（具体待定，可与 Arc7 终极真相挂钩）
- **大能"诱饵"里的真东西**：突破丹 1-2 颗（顾生暂时不用，留 Arc7 收尾时用）
- 教众供奉持续累积

### 戏份硬指标
- **ch112 反算计章是 Arc6 顶点**，单章可超 3000，必须把"反算计步骤+大能反应+境界压不破+偷真东西"四件事一并兑现。这是**精神层面的实力大爆发**，不是境界突破。
- **筑基后期·满的"满"感**在 ch113-115 多次复现：灵力厚到一指可碎石、本命飞剑剑魂第二阶段、上古真功法初步运转。读者会清楚知道"再补一锤就能上大圆满，主角故意忍着"。
- **每弧"实力差展示"**：大能展示化神之上境界那一笔必写。

### 与阴谋线/妖兽线的咬合
- **反算计大能 = 阴谋线（与古物里的存在博弈）+ 实力线（从大能那里偷真功法/法宝）**：这一次，**实力进账本身就是博弈的战利品**。
- **护法网 = 撤离/传讯基础**：顾生气息暗暗暴涨，护法网为他制造"焦点转移"假象，让追查者扑向另一处"异常看见者"。

### Arc6 仍需在写正文时定的实力细节
