## 核心阴谋：苍梧镇的卧底
苍梧镇不是世外桃源。镇上有**一个披着凡人皮的卧底/妖物**（顾生用第二重视界——看见伪装/本相——识破），它在执行一个**针对凡人的长期阴谋**（待定：监视某物/收集某种凡人气息/养蛊/为某个势力埋钉子）。

顾生**看破了它的本相和阴谋**，但他一个废灵根，**说破没人信**（谁信一个郎中说"镇上的张三是妖怪"），**动手又打不过**。他只能用"看破不说破"的方式——**装作偶然、借刀、布局**——在不暴露自己能力的前提下除掉它。

## 章节推进
| 章 | 事件 |
|---|---|
| 16 | 流浪到苍梧镇。落脚，当郎中，扎根（凡间温情线） |
| 17-19 | 行医+暗修（常规修炼）。古物第二重视界开始解锁，他开始"看见"伪装的痕迹；行医时救下几户凡人，留下"顾大夫能救苦"的朴素口碑 |
| 20-22 | "看见"镇上某人（卧底）的本相不对。开始暗中观察、拼它的阴谋；小规模瘟疫/井水污染/邪祟伤人事件中，顾生用医术和一点不暴露来源的"神异手段"让凡人愿意听他的防疫、净水、避灾规矩。这里开始写出救苦口碑从一户、一巷到一村的扩散，不是单点感谢 |
| 23-25 | 拼清卧底的目的+背后势力。**看破，但不能说**——说了没人信+暴露自己；被救过的凡人私下立无名牌位或小龛，"顾大夫能救苦"传成"救苦人"的土称。这个群众基础是 Arc3 妖父子能冒充"座下护法"的前提 |
| 26-28 | **布局**：顾生用一个不暴露"我看见了"的方式（借镇上猎户的手/借某次妖兽事件/借卧底势力的内斗），除掉/逼走卧底（**坏妖**，杀之有理）。**第一次完整的"看破不说破→借刀→翻盘"** |
| 29 | 除掉一个，牵出更大的网——卧底背后有势力，苍梧镇的危机不是孤立的。**第二明线萌芽**：顾生赶路/采药途中误打误撞撞见**蠢萌幼年小妖**（奶凶呲牙护食），现代人灵魂没舍得杀，放过它（创世故事 1-2 步） |
| 30 | **Arc2收尾**：顾生意识到自己已卷入更大的棋局，无法独善其身；"救苦人"的传闻留在凡间，但不能指向青玄宗顾生。|
