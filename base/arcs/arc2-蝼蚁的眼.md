## 主角本弧动机（必须先于一切）
**提升实力、在乱世中苟命**——这是 Arc2 的主轴。Arc1 节点① 兑现后，刘波离宗、第一个念头是"必须把实力提上来"。本弧他游走沧溟三十六寨，**第一目的是暗修（苦修 + 采药 + 查炼气期资源）+ 躲万仙宗清除余波**。

- **救人是副产物**：路上撞见的、被凡人/妖兽/灾厄逼出来的。每救一次都有暴露代价，他每次都先算"值不值"。
- **行文硬指标**：每章正文都让读者明白"他在炼气 / 在偷资源 / 在算计 / 在躲追查"，救苦只是这条主轴的侧写。**绝不写成"隔壁好心的大夫发善心"**——他是修士，不是乡村郎中。

## 核心阴谋：沧溟三十六寨的卧底
沧溟三十六寨不是世外桃源。这片方圆数百里的边荒流民地带，散布着一个**披着凡人皮的卧底妖物 cell**（柳七/吴婶/孟先生，详见 `../../characters/沧溟卧底-*.md`），他们是**更大网络在"三十六寨这一节"的管理者**。cell 在执行一个**针对凡人的长期阴谋**（监视/收集凡人气息/养蛊/为某势力埋钉）。

刘波**用第二重视界——看见伪装/本相——识破 cell**，看破了他们的本相和阴谋。但：
- **不能说破**：揭穿=暴露自己有"看见"的能力=立刻被更高层盯上。
- **动手打不过**：cell 三妖都是筑基期，他一个废灵根，正面打是送死。

他只能用"看破不说破"的方式——**装作偶然、借刀、布局**——在不暴露自己能力的前提下除掉 cell。

> 注：道人降妖本是修士本分，所以"说了没人信"的旧逻辑不成立——本弧的矛盾不是"凡人不信一个郎中说张三是妖怪"，而是**"道人识破妖邪本应正面对决，但刘波不能——因为他的'识破'靠的是古物，一说破就暴露古物存在，而古物是他活命的底牌"**。看破不说破从"凡人不信"升级为"修士世界的自保"。

## 章节推进（修炼驱动版）

> **每章的根本驱动力 = 找资源→修炼**。"暗修/采药/查资源"不是嘴上动机，是推动每章事件的主引擎。照墟玦的修炼辅助能力（看穿药材真伪/灵石纯度/功法阉割/精准引气）是废灵根能逆袭的唯一支点——详见 ../world/01-古物与金手指.md §六。

## Arc2 阴谋设计决策（已定，见 characters/）
### 卧底 cell
- **柳七**：蛇妖（黑鳞），化形年久，筑基中后期，三十六寨某寨东头杂货铺老板（"厚道人"）。知道 cell 是更大网络的一节。
- **吴婶**：黄鼠狼妖，筑基初期，三十六寨某寨西头卖豆腐妇人（"好心的吴婶"）。cell 中最"像人"——她不是"装善良"，她"做善良"。
- **孟先生**：**青丘狐杂支**，筑基中后期，三十六寨某寨北头教书先生（"不收穷孩子束脩的读书人"）。cell 中最有故事的——青丘一脉的边缘血脉，伏笔留 Arc6+ 拉出。
- 三妖分驻三十六寨中相邻的数寨，各自经营一片凡人区域，组成 cell 的"一节"。
- 详见 `../../characters/沧溟卧底-柳七.md`/`吴婶.md`/`孟先生.md`。

### 阴谋目的
- 长期收集凡人气息（柳七子时林子取气、吴婶清晨处理残痕、孟先生 7 日一次荒庙转运）。
- 通过地下通道送往天玄圣地方向（ch20 揭示）。
- 三十六寨不是孤案，是更大网络的一节。"上面"留 Arc4+ 揭。

### 借刀手法
- 不直接揭穿——借 cell 内部矛盾 + 借凡人社会的力 + 借 cell 之一（孟先生最易动摇）反水。详方案见各人物档案。

## 救苦口碑线（第二明线·本弧铺垫，独占 Arc3 主导）

> 这是与阴谋线并列的第二明线的**前期铺垫**。本弧只累积"群众基础"，不点破神号、不解释功德机制。详见 `../../progress/foreshadow.md` 第五线。

**口碑三段递进（本弧 + Arc3 前半）**：
1. **"收邪先生"（土名）**：ch16-18，单寨凡人视角。某人家的水鬼被收了、某条道的山魈被镇了——凡人称"那位云游道长能收邪"，土名自然长出。
2. **"能镇邪的高人"（区域共识）**：ch19-24，随足迹扩大，数寨凡人都听说过。从一寨传到数寨，从"能收邪"升级为"能镇邪的高人"。
3. **"救苦天神"（神名固化，留 Arc3 ch37-42 完成）**：当口碑从"收邪"扩到"化解旱涝/瘟鬼/妖祟压寨"等灾厄，凡人对他的认知从"会法术的人"升格为"救苦救难的存在"。**民间先有"天神"传闻，Arc3 妖父子才能假冒"救苦天神座下护法"**——这是逻辑前提。

**神迹类型（分阶段）**：
- ch16-18 **降妖除祟为主**（贴合 cell 阴谋线，低阶妖祟，实力线内合理）。
- ch19-24 起加入**灾厄化解**（旱涝、瘟鬼、妖祟压寨）——神迹尺度升级，口碑从"能收邪"扩到"救苦"。
- **治病退居二线**：仅用于处理凡人外伤/中毒（医者本能 + 降维禁令内），**不构成口碑主体**，凡人不会因医术称他"神医"。

**载体（替代旧"净井救疫"设计）**：
- 口碑活证据从"一个被救活的孩子"改为**"散布在三十六寨的多起降妖事迹"**——某个寨子的水鬼被收了、某条道的山魈被镇了、某户人家的邪祟被驱了。证据从"一个人"变成"一片地方的传闻"，更贴合"足迹广→传闻广"。
- 信仰反讽伏笔（接 Arc7）从"陈嫂立无名牌位"改为**"三十六寨多处凡人自发立的无名小龛/纸符"**——散点式，非单一人物载体。Arc7 揭破"信仰喂照墟玦"时，情感重量更大（一片土地的善意 vs 一个人的善意）。

## 实力推进重点

### 修炼循环骨架（本弧主线引擎）

> arc2 修炼不是抽象的"苦修"，而是**照墟玦驱动的"多资源循环"**。这是废灵根能逆袭的唯一支点——没有照墟玦他发现不了资源、判断不了真伪、炼不准灵气路径。照墟玦的能力边界见 ../world/01-古物与金手指.md §六（只给信息不给力量）。

**五步循环**（每个修炼章的骨架，可多步合一章）：

1. **发现**——照墟玦看见别人看不见的资源：野生灵药真伪（ch16）、灵脉边角走向（ch15）、妖兽内丹品质、废弃阵图阵眼（ch17）、功法残页阉割处（ch24）、cell 抽气的灵气流向异常（ch18）。
2. **获取**——用算计/借刀/交换/顺手牵羊拿到，**不一定是正面抢**：采药（ch16）、杀妖收核（ch16-17）、将计就计化解标记后净收宋清漪丹药（ch20）、偷修 cell 矿道（ch22-24）、借刀杀 cell 清点储物袋（ch25-27）。
3. **炼化**——照墟玦辅助精准引气/炼药/炼化妖核：五灵根五路径，废灵根变优势（ch17 夜修、ch28 后院煮汤式补法）。
4. **突破**——境界推进，境界突破章四件套照旧（ch29 大圆满）。
5. **试炼**——把新能力/新底牌实战验证，与下一章战斗/事件咬合（ch17 借阵杀妖、ch28 试炼新底牌打低阶妖兽）。

**arc2 具体兑现**（每章走完哪几步，见章节推进表"修炼收获"列）：
- ch15：发现（灵脉边角）+ 突破（炼气二）
- ch16-17：发现（灵药/阵眼）+ 获取（杀妖收核采药）+ 炼化（夜修）+ 突破（炼气三）+ 试炼（借阵杀妖）
- ch18-19：发现（cell 抽气真相）—— 这步的"获取"留到 ch25-27（夺回修炼场+战利品）
- ch20-21：获取（宋清漪资源，化解标记）+ 突破（炼气四）
- ch22-24：获取（偷修据点+阉割功法）+ 炼化（私修真版修正）+ 突破（炼气五）
- ch25-27：获取（杀 cell 大进账）+ 突破（炼气七，跨两阶）
- ch28：炼化（拆妖核/吸灵石/对功法）+ 试炼（新底牌打低阶妖兽）+ 突破（炼气九）
- ch29-30：炼化（大圆满突破消耗资源）+ 突破（炼气大圆满）

**废灵根吸留比渐变**（arc2 贯穿）：起三七开（吸十留三，资源消耗大产出低，ch22-24 卡瓶颈的根因）→ 经照墟玦精准引气+真版功法修正+妖核炼化 → 终七三开（吸十留七，大圆满时废灵根逆袭完成第一阶段）。

### 第一次越阶战斗（Arc2 大爽点·借刀型越阶）
- 对手：柳七（蛇妖，筑基中后期）+ 吴婶（黄鼠狼妖，筑基初期）
- 越阶情况：炼气大圆满 vs 筑基中后期+筑基初期——**理论上必死局**
- 手段：**借刀**——不正面打，用阴谋线手段（cell 内斗）让吴婶先死、柳七疑吴婶反水→孟先生反水→柳七被万仙宗外门弟子（炼气大圆满）顺势猎杀
- 刘波本人最终出手：只清理 cell 已破后"漏网最弱的一只"（吴婶手下小妖兽）——同阶顶端碾压，证明"我能打同阶"
- **教训写法**：让读者明白"越阶战斗≠正面打"——**布局型越阶是这一阶段的主旋律**

### 与三线咬合（修炼是主线，三线服务于修炼）

> arc2 不再是"阴谋/救苦/妖兽三线驱动、修炼依附他线"。**修炼是主线**，三线都是修炼循环的"发现/获取/试炼"步的载体：

- **阴谋线（cell）服务修炼**：cell 抽干区域灵气 = 毁刘波修炼场（ch18 发现）→ 除 cell = 夺回修炼场 + 拿筑基期突破资源（ch25-27 获取）。阴谋胜利的副产物全部变成修炼资源进账。
- **救苦线服务修炼**：降妖除祟是采药/查资源途中的副产品（ch16-17 为灵药杀妖、ch22-24 为偷修作掩护）——救人是顺带，找资源是根本。救苦口碑累积（"收邪先生"）是修炼途中的意外声誉。
- **妖兽线服务修炼**：ch28 妖父子初遇发生在采药/试炼新底牌途中——是修炼循环"试炼"步的副产品。
- **宋清漪线服务修炼**：她的资源试探 = 刘波的修炼资源获取（ch20-21 化解标记净收），同时是互相试探的人物关系节点。
- **ch28 妖父子初遇前夕已是炼气大圆满**——读者期待"他下一步该筑基了"，**为 Arc3 ch36 蓄力**
