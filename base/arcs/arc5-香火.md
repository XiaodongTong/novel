# Arc 5：香火（新增，~ch73-92，妖兽主导）

> 隶属 ../spine.md。冲突时以 ../spine.md + ../world 为准。
> **本书第二条妖兽主导弧。** 主线B 的「扩张 + 失控」落在这里：护法网铺开，又因点化成功的副产物而失控。
> **基调**：暖中带乱——喜剧（更多蠢萌妖来投）与失控（投机者/恶妖照抄作恶）交织。

---

## 主导线（妖兽）：护法网扩张 → 失控
- **扩张**：混不下去的妖陆续来投（每只一个小点化故事），教众变多，势力范围极速扩张。原始妖父子俨然"开宗立派"。
- **失控**：这条"冒充护法能活得不错"的路一传开，被投机妖/恶妖照抄 → 假护法、借名敛财、恶妖混入害人。失控能迅速蔓延，正因为 Arc2-3 已经铺出"救苦天神"的民间群众基础：百姓愿信、愿供，也急需有人回应祈求。原始妖父子想管管不住。
- 顾生不得不**暗中收拾**这个用他都不敢认领的神名作恶的烂摊子，却仍不能认领本尊、不绑青玄宗。

## 暗流（细阴谋）：追查"异常看见者"逼近
- Arc4 的大型权谋战后，某高层意识到"有人在暗中看破并操纵一切"，开始追查「泄密者 / 暗中操盘者 / 异常看见者」。
- **张力校准**：追的是"能力痕迹"，不是顾生本人。护法网的失控**恰好制造了更多"异常痕迹"**，追查顺着这些痕迹逼近——顾生必须**亲手掐断快要被拼上的环节**（销毁痕迹、误导方向、制造另一个"异常看见者"假指向）。绝不让线索拼成"假死的顾生还活着"。

## Arc5要解决的设计问题
- 护法网失控的具体形态（假护法害人事件 1-2 个）+ 顾生暗中收拾又不暴露本尊的手法
- 追查"异常看见者"逼近时，顾生"亲手掐断的那一环"具体是什么
- 新来投的妖里，挑 1-2 只设计成有记忆点的（延续蠢萌/各有怪癖）

## 实力推进（Arc5：综合实力爆发期——幻术+阵法+本命飞剑全维度展开）

> 详见 [04-修炼成长.md](../world/04-修炼成长.md)。**Arc5 不是境界爆发弧，是八维综合实力的爆发弧**——学会幻影分身、布筑基级杀阵、本命飞剑炼成第一阶段、暗除恶妖批量碾压同阶。

### 境界起→终
- **起**：筑基中期（Arc4 末）
- **终**：**筑基后期**（仅一阶推进，但八维全面展开）

### 推进节奏
| 章 | 修为推进 | 触发 |
|---|---|---|
| 73-77 | 筑基中期·稳固 | 教众扩张 = 供奉灵物增多。蠢萌妖来投常带"投名状"（自己采的妖核/灵草）。本命飞剑炼化第一阶段 |
| 78-83 | 筑基中期 → 筑基后期·瓶颈 | 失控初现，顾生暗中观察+小试身手。这阶段灵力消耗大但实战经验暴涨 |
| 84-88 | 筑基中期 → **筑基后期** | **暗除恶妖批量收割期**——假护法/恶妖每除一只就是一份资源。**ch88 推到筑基后期**，与第一次正面打金丹初期同章 |
| 89-92 | 筑基后期·稳固 | 故意不破大圆满（给 Arc6 反算计大能时拿真东西留契机） |

### 八维进账（Arc5 核心 = 三个新维度爆发）
| 维度 | Arc5 新进账 | 来源 |
|---|---|---|
| **修为** | 筑基中期 → 筑基后期（一阶） | 教众供奉灵物 + 暗除恶妖批量妖核 + 苦修 |
| **功法** | 完整真功法稳固运转；教众供奉中的杂学典籍（幻术/阵法启蒙）；**第一次接触上古残篇**（一行字一行字看穿） | 教众供奉 + 苦修 |
| **法宝** | **本命飞剑炼化第一阶段完成**（剑魂初具，可指令御剑而非只能放飞） + 假护法搜刮的供奉里的法宝 + 暗除恶妖夺的法宝 | 本命联结 + 战利品 |
| **攻击** | **多技组合·攻势成体系**（飞剑+杀阵+符箓三联）+ 真功法的连招版（前+后式连贯） | 实战+苦修 |
| **防御** | **妖兽幻术做替身**（用幻影替身吸住敌人主攻，本体撤）+ 真气护体升级 | 学幻术副产物 |
| **逃跑** | **幻影分身遁**——本体藏在分身后 + 假死遁地（一个新法门） | 学幻术 + 妖兽传承 |
| **幻术** | **学会幻影分身·一变三**（妖父子+教众妖兽教授+顾生自学）——**Arc5 最大新维度突破** | 妖兽传承 |
| **阵法** | **布筑基级杀阵/迷阵**——能独自布出能困住筑基大圆满半时辰的杀阵；能布出迷阵让追兵迷路 | 苦修+实战 |

### Arc5 越阶战斗·**ch88 第一次正面打金丹初期**
- **对手**：一个借神名敛财的金丹初期恶修（建议设计成"前宗门叛徒，靠护法网漏洞做局"，恶妖与人混编势力的主脑）
- **越阶情况**：**筑基中期/后期临界**对**金丹初期**——一阶半的差距
- **手段**：六维叠加——
  1. **本命飞剑·剑魂初具**——首次发挥本命级威力
  2. **完整真功法连招**——真功法的杀招连贯施展
  3. **幻影分身**——一变三，对方分不清本体
  4. **筑基级杀阵**——把对方困在阵中
  5. **看见破绽**——古物盯死对方一招起手的灵力轨迹
  6. **护盾法宝**——扛对方一记必杀
- **结果**：**正面 KO**——读者第一次直观看到顾生"越阶打金丹"。但他**全身真气耗尽，本命飞剑剑魂回炉养三天**。代价兑现。
- **同章爽点**：金丹气息散尽时顾生的一句"我也是个大夫，治不好你这种病"——口头禅成杀手锏。

### 同阶碾压实写
- ch78-87 期间，暗除恶妖批量行动——筑基初期/中期/后期的恶妖、假护法、借名敛财的人妖修士，**几乎每章一只**，**整个 Arc5 是同阶碾压的密集展示弧**。读者会真切感受到"筑基期顾生在同境界里是顶端"。

### 实力差展示
- ch89-91 追查者升级到**金丹中期**修士直接出动追"异常看见者"。顾生**立刻收手撤离**——金丹中期不是他能正面打的。让读者看见上限。

### 关键资源进账
- **暗除恶妖批量妖核**（约 5-10 次行动）：累积金丹级妖核 5+ 枚、筑基级若干
- **教众供奉灵物**：上品灵石、灵草、丹药稳定供应（不主动收，但护法网汇集到他这边）
- **假护法搜刮品**：恶妖借神名敛财积累的脏物，顾生暗中接收，等于"二次收割"
- 上古残篇若干（教众供奉中的"破书"，实为上古修士遗物——Arc6 封印地的伏笔）

### 戏份硬指标
- **ch88 越阶战 = Arc5 顶点章**，单章可超 3000，必须把"六维叠加+全身耗尽+口头禅杀手锏"一并兑现。
- **金丹气息+幻术+阵法**的"实力跃升"画面在 Arc5 整弧密集出现——每弧硬指标"4-5 个维度有进账"在 Arc5 是全维度展开。
- **每弧"实力差展示"**：ch89-91 金丹中期追查者出动那一笔必写。

### 与阴谋线/妖兽线的咬合
- **暗除恶妖 = 阴谋线（追查者难抓痕迹的"看破不说破"手法）+ 妖兽线（清理护法网失控）+ 实力线（批量收割+实战练兵）三线同帧**
- **学幻术 = 妖兽线副产物 = 实力线新维度爆发**——妖兽传承的"暖"在 Arc5 转化为顾生新的"硬实力"

### Arc5 仍需在写正文时定的实力细节
- 暗除恶妖的具体数量与节奏（建议 5-8 次，散落各章）
- ch88 金丹初期对手的具体背景与名字
- 顾生学幻术的具体方式——是妖父教？妖崽教？教众里某只妖（建议设计一个新的妖兽角色——"狐姑"，黄鼠狼妖陈婶死后流落出来的同族遗孤，化形漂亮，幻术天赋高，主动来投护法道）
- 上古残篇的具体形态（破书/玉简/碎符——建议玉简，与 Arc6 封印地形成线索链）
