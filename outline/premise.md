# 故事前提

## 一句话概括

一个被修仙界抛弃的低阶修士，在百年残命中选择守护凡人，最终悟出众生信仰即最强大道。

## 核心冲突

修仙者视凡人为蝼蚁、为修炼资源。凡人苦不堪言，却无力反抗。
主角身为修士，却心系苍生，站在了整个修仙界的对立面。

## 故事内核

**"大道之行也，天下为公。"**

修仙的本质不是逆天而行、独善其身，而是心怀天下、与众生共进。
凡人的信仰与感恩汇聚成河，才是这个世界最本源的力量。
修仙界的高高在上，恰恰是离大道最远的歧途。

## 主角弧光

```
怯弱隐忍的外门弟子
  → 被迫害驱逐，万念俱灰
    → 在凡人间找到存在意义
      → 以凡人之友的身份战斗
        → 勘破众生之道
          → 以众生之力撼动修仙界秩序
```

## 三幕结构

### 第一幕：修仙界的蝼蚁（约 75 章，~20 万字）
- 穿越、拜入宗门、受尽欺压
- 目睹修士对凡人的冷漠与残忍
- 被算计驱逐，身负重伤

### 第二幕：百年的抉择（约 150 章，~40 万字）
- 流落凡间，看见真实的疾苦
- 决定用残命守护一方百姓
- 与妖修鬼怪斗，与大旱天灾斗
- 用修士法力+现代知识改变凡人命运
- 逐步发现信仰之力的秘密

### 第三幕：众生之道（约 75 章，~20 万字）
- 勘破世界隐藏法则
- 信仰之力觉醒，实力质变
- 与修仙界旧秩序的终极对决
- 建立新秩序：修仙者为众生而修
