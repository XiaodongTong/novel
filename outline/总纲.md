## 总体节奏曲线
- **爽感**：每3-5章一小爽（小识破/小反杀），每15-20章一大爽（大阴谋瓦解/真相揭露）。
- **威胁**：随主角深看的深度，暴露威胁从"寒意"→"巧合追查"→"直接清理"递增。
- **结构**：每弧 = 一条主导线（阴谋 or 妖兽）+ 一条暗流（另一线）+ 看破/不能说破/夹缝布局/翻盘/代价。
- **双明线交替**：阴谋线（冷）与妖兽点化线（暖）**逐弧交替主导**，冷暖对照调节节奏；两线到末弧**收束合一**。

## 前期双线护栏（写正文前必读）

> 来源：`../docs/plan/逐出宗门-与-万民功德-双线方案.md`。该方案是 **后期**的主线（公开逐出 + 万民功德）。前段七弧只做**铺垫**，但必须铺对。

### 护栏一：假死识破是后期的后置节点（前段绝不触发）

- **顾生在青玄宗官方记录里已"死"**（ch7-15 假死脱身）。让宗门中高层把"顾生没死 + 当年假死脱身"拼成结论，是 **前段七弧之后**才发生的死局节点，**前段一律不得触发**。
- **原因**：前期主角没有实力、名气、资源、民间基础去反向架住宗门，一旦被中高层确认活着，逻辑上直接被低成本灭口，小说没法写下去。
- **前期追查只能追到"能力痕迹"，不能追到"人"**：敌人知道"有人在暗中看破并操纵"，但拼不出"那个人就是当年死掉的杂役顾生"。追查对象写成「泄密者 / 暗中操盘者 / 异常看见者」，**绝不写成「追查假死的顾生」**。
- **可以写**：青玄宗附属势力、地方执行网、秦长老留下的旧案制度阴影、金丹/元婴级幕后。**禁止写**：秦长老本人确认顾生没死、幕后把线索锁定到"青玄宗杂役顾生"。

### 护栏二：救苦救难 + 妖兽点化 = 第二明线（与阴谋主线并列，逐弧交替主导）

- 救苦/妖护法**不是副线种子**，而是**与阴谋主线并列的第二明线**，且**独占 Arc3、Arc5 两条主导弧**（详见下文「第二明线」专节）。它给读者"在乎主角"的暖，与阴谋线的"冷"形成节奏对比。
- 但**动机护栏不变**：顾生做救苦，动机始终是"活下去 / 护住眼前人 / 处理眼前危机"；点化妖兽，是"现代人灵魂没舍得杀"的本能，不是主动收编打手。**救苦/点化常与破阴谋同章发生**（救人是接近阴谋现场的掩护；妖护法网后期是破阴谋的耳目）。
- **妖兽弧不能做成纯暖、零阴谋的封闭弧**：Arc3、Arc5 虽妖兽主导，但每弧都保留一条细阴谋暗流（顾生此刻在躲什么/查什么），让救苦始终是"处理眼前危机"的副产物，而非主角专门去经营神号。
- 神号**先土后正**：前期只长出"救苦人 / 救苦先生 / 救苦天神"的民间土称，**不正式解释功德机制、不出现「青玄·救苦天神·顾生」三段式神号、不绑定青玄宗身份**。这些全留到后期。
- 顾生本人对被供奉/被冒充**可以不知情，或知情后一笑不理、不认、不解释**——避免他提前变成高调宗教领袖。
- **命名规约**：正文一律称**妖兽**。不用"山精野怪 / 小土地 / 庙祝残魂 / 精怪"等词（那些只是讨论用语）。妖兽**和人一样是这世界的生灵、一样分好坏**，彼此差别只在**灵智高低 / 能否化形 / 善恶**三条连续轴上。主角杀恶妖（如 Arc2 卧底）、点化善妖，与"杀坏人、帮好人"同理，不是双标。

### 护栏三：前期威胁三来源（与假死身份解耦）

假死识破后移后，前期的压迫感**全部**来自以下三处，与"宗门追杀假死的顾生"无关：

1. **看见=暴露**：深看招来未知存在的清理（寒意→巧合追查→认知抹除，递进）。这是贯穿全书的根威胁。
2. **追查异常看见者**：势力追查"有人在看破操纵"，逼近到**差一点拼出顾生**——张力是"他必须亲手掐断那条快要连起来的线"，不是肉身逃杀。
3. **大能博弈**：古物里的存在提条件、选择性透露、引导顾生。

### 护栏四：章节弹性——前段七弧拉长，节点顺延

- 第二明线升格 + 独占两条主导弧后，**前段从约 100 章自然延展到约 120-150 章**（写正文时定）。上方总览表的章号是**相对示意**，不是死限。
- 三层钩子、三个节点、书名兑现（公开逐出）、后期主线，**全部按比例顺延**，相对顺序不变：钩子1/节点①在 Arc1，钩子2/节点②在 Arc4，钩子3/节点③在 Arc7。
- 已写定的 Arc1（ch1-15）、Arc2 开篇（ch16-20）不动。

## 第二明线：妖兽点化 → 护法教 → 万民胚胎

> 与阴谋主线**并列**、独占 Arc3 / Arc5 两条主导弧的第二明线。基调与阴谋线**冷热对比**：阴谋线冷（权谋 / 憋 / 暴露），这条线暖 + 萌 + 喜剧。它给读者"在乎主角"的理由，也是后期「万民之主」的组织胚胎。
> **创世故事 = 蠢萌妖父子点化样板**（下），是这条线的起点正典。

### 一句话机制：点化

```
遇善妖(灵智高/本性善) → 主角不一杀了之(感人际遇,自行设计)
→ 妖短暂追随 → 见证主角救人、收谢礼香火 → 分别
→ 妖自悟"冒充恩人(救苦天神座下护法)能活得不错:有香火功德 + 百姓供养"
→ 自立护法道场 → 有求必应 → 收编混不下去的妖 → 教众扩张
```

- "冒充"= 妖**自封**，主角未必知情、更没正式收编。点化是"被打动"，不是"签契约"。
- 这条路一传开，也会被投机/恶妖照抄 → 自然长出"假护法、借名敛财"的失控线（无需额外设计，失控是点化成功的副产物，落在 Arc5）。

### 创世故事：蠢萌妖父子（第一护法的起源）

> 落在 Arc2 弧尾（初遇）— Arc3 头（求救→医生→无处可去→见证→分别→回不去→一拍即合）。感人细节写正文时自行设计，以下为节拍骨架：

1. **初遇**——顾生赶路 / 采药途中误打误撞撞见一只**幼年小妖**：蠢萌懵懂、又带点小狡黠。实力弱小，但**灵智在妖族中绝无仅有**。
2. **没舍得杀**——小妖奶凶奶凶呲牙护食 / 护地盘。顾生（现代人灵魂）下不去手，放过了它。（小妖回去还挨妖母数落：怎么没把人吓走。）
3. **求救**——小妖的**父亲**在妖兽斗争中惨败、生命垂危、举目无援。小妖**机智地**找上顾生求救。
4. **医生发挥**——顾生施展凡间医术（对妖兽是降维）+ 一点不暴露来源的手段，救回妖父。
5. **无处可去**——被救的妖父子在族群里已混不下去，**悄悄跟着顾生**。顾生察觉了，**嘴角一勾，没理会**。
6. **见证**——父子一路看顾生救村民、被千恩万谢、立龛烧香。
7. **分别**——顾生离开（远行 / 御空，看届时实力），父子幼弱跟不上，只得留下。
8. **回不去了**——饥肠辘辘的父子斗着嘴把供奉吃了个精光。"真饱!"——茹毛饮血，哪有人类煮熟的猪头香？从此回不去山里了。
9. **一拍即合**——狡黠的父子合计：既然恩人走了，不如**冒充恩人**（救苦天神座下护法），既收香火，又有百姓供养。第一护法道场就此诞生。

### 主线B 推进阶梯（映射到各弧）

| 阶段 | 落点弧 | 事件 | 与阴谋线的咬合 |
|---|---|---|---|
| **萌芽** | Arc2尾–Arc3头 | 妖父子初遇→点化→追随→分别→冒充护法（创世故事） | 救村民是破阴谋的掩护 |
| **成形** | Arc3 | 第一护法道场"有求必应"：驱鬼、除妖（降伏后收作小弟）、妖法治病 | 护法成顾生在凡间的耳目 / 传声筒 |
| **扩张** | Arc5头 | 混不下去的妖陆续来投（每只一个小点化故事），教众变多，势力极速扩张 | 护法网 = 破阴谋的情报 + 传播 + 掩护 |
| **失控** | Arc5 | 投机者/恶妖照抄 → 假护法、借名敛财、恶妖混入。原始妖父子想管管不住 | 顾生须暗中收拾，不认领本尊、不绑青玄宗 |
| **跨界** | Arc7 | 人类散修也加入教众 → 已是跨人妖之"教" | 万民胚胎；Arc7 终极真相处**两线合一**（信仰喂古物） |

### 暗线（前期只埋不揭，留后期）

- **信仰喂古物**：护法教收的香火，表面养妖、养主角名声，实则**喂养古物里的大能**，加速其苏醒。父子吃供奉"真饱"的喜剧面下，藏着这条暗黑暗线。前期只用大能一两句暧昧话暗示，到 Arc7 终极真相处揭破——这也是两线合一的支点。
- **万民之主**：教众（妖 + 人）是后期"万民之主"的组织雏形，前期不点破含义。

## 阴谋故事清单（用户要求：配合几个阴谋故事）

本书的每个"阴谋故事"都是一个完整的**看破→不能说破→夹缝布局→翻盘→代价**循环。已规划的核心阴谋（阴谋主导弧）：

1. **Arc1：清除名单**（宗门对边缘者的例行清除）—— 见 [arc1](arcs/arc1-坠崖与眼.md)
2. **Arc2：苍梧卧底**（披皮妖物的长期渗透）—— 见 [arc2](arcs/arc2-蝼蚁的眼.md)
3. **Arc4：功法/历史阴谋链**（高层掩盖真相的大阴谋）—— 主菜，见 [arc4](arcs/arc4-棋子.md)
4. **Arc6：双面棋局**（外面追查逼近+里面大能引导，顾生反算计）—— 见 [arc6](arcs/arc6-被注视的眼.md)
5. **Arc7：终极真相**（秩序、未知存在、大能棋局，两线合一）—— 见 [arc7](arcs/arc7-真相与火.md)

> 妖兽主导弧（**Arc3 点化 / Arc5 香火**）各保留一条细阴谋暗流（Arc3：凡间盘剥/猎杀线；Arc5：追查异常看见者），让救苦/护法始终是"处理眼前危机"的副产物。

每个阴谋都要有：**一个伪装得很好的反派/幕后、一层层剥开的真相、顾生看破后的憋屈与翻盘、真实代价。**

> **第二明线**：救苦救难 → 神名雏形 → 妖兽点化冒充护法 → 护法教 → 万民胚胎，独占 Arc3 / Arc5 两条主导弧，见顶部「第二明线」专节。它与阴谋线交替主导（冷/暖对照），是后期「公开逐出 + 万民功德」主线的前期胚胎，暗线（信仰喂古物）前期只埋不揭、Arc7 揭破。
