# 总纲 —— 前100章五弧线 + 阴谋事件清单

> 与 `../story/SPINE.md` 配套。SPINE 给骨架，本文件给**每弧的具体阴谋事件 + 章节级推进**。
> 这是"配合几个阴谋故事、看破不能说破、夹缝求生"的落地清单。
> 冲突时以 `../story/SPINE.md` + `../worldbuilding/` 为准。

---

## 总体节奏曲线
- **爽感**：每3-5章一小爽（小识破/小反杀），每15-20章一大爽（大阴谋瓦解/真相揭露）。
- **威胁**：随主角深看的深度，暴露威胁从"寒意"→"巧合追查"→"直接清理"递增。
- **结构**：每弧 = 一个核心阴谋 + 顾生看破 + 不能说破 + 夹缝布局 + 翻盘 + 代价。

## Arc 1：坠崖与眼（ch1-15）

### 核心阴谋：青玄宗的"清除名单"
青玄宗（代表秩序的基层）有一份不成文的**清除名单**——那些"差一点就要出问题"的废灵根/边缘修士（指标：灵根异常、被某东西轻微注意、差一点觉醒某种感知）。赵玄机是执行者之一。踹顾生下崖，是一次例行清除。

顾生用古物**看破**了这个名单的存在（第三重视界雏形——他看见赵玄机对某几个杂役的"特殊关注"模式、看见某次清除后的痕迹），但他**不能说破**——说破=坐实他"有问题"=立刻被重点清除。

### 章节推进
| 章 | 事件 | 主角主动决策/行为 |
|---|---|---|
| 1 | 被踹下崖→濒死抓古物→钻入掌心→视野变了→躲过补刀。**开篇即冲突即金手指。** 钩子：看见崖壁里流动的光 | 抓住古物（求生本能）；装死躲过补刀者视线 |
| 2 | 回宗装没事。古物偶尔让他"看见"模糊灵气流向。第一次在小事上用"看见"占到便宜（识破某个针对他的小算计） | 在被欺压时"无意"指出对方灵力走偏，让对方当场失态 |
| 3 | 第一次深看→**那阵寒意**出现（暴露机制种子）。顾生以为是错觉，但记住了 | 决定"下次深看前先想清值不值"（主动克制） |
| 4-5 | 古物能力渐显。顾生察觉赵玄机对"某几个杂役"的特殊关注模式（第三重视界雏形） | 主动开始**记录**赵玄机关注谁/不关注谁（行为级） |
| 6 | 卷入边缘：某个被赵玄机"关注"的杂役失踪了（被清除了）。顾生"看见"了清除的痕迹 | 决定**不声张**，但把那个杂役的遗物藏了一片（伏笔） |
| 7-10 | **钩子1半揭/全揭+第一次大爽点**：顾生确认古物让他"看见"，并用它**反杀**了一个算计他的人（某个奉赵玄机之命来试探/处理他的人）。**看破不说破**的第一次完整实践 | 主动**设计一个"被试探"的局**，让对方先露马脚再反制 |
| 10 | **代价**：反杀那次深看，引来第一次实质性后果——有人开始调查"最近怪事"，顾生险些被牵连 | 主动**站出来做伪证人**，用看见的信息编"合理怀疑"误导追查方向 |
| 11-14 | **节点①**：为脱身，顾生不得不**放弃某样东西**（一个本想保住的机会/一段关系/一个想保护的人的信任）。赢得反杀，输了别的 | 决定**主动交出**最在乎的某样东西（信任/药方/承诺）换脱身 |
| 15 | **Arc1收尾**：顾生身份暴露/被逐/逃。带古物和"这世界在清除某种人"的认知，进入凡间 | 选择**主动逃**（不是被逐），且**主动留陷阱**给追踪者 |

### Arc1要解决的设计问题（写正文前定）
- 顾生"放弃"的那样东西具体是什么？（需有痛感）
- 反杀的具体方式（看破+布局，不能靠武力）
- 离开青玄宗的契机（被逐 vs 主动逃）

## Arc 2：蝼蚁的眼（ch16-30）

### 核心阴谋：苍梧镇的卧底
苍梧镇不是世外桃源。镇上有**一个披着凡人皮的卧底/妖物**（顾生用第二重视界——看见伪装/本相——识破），它在执行一个**针对凡人的长期阴谋**（待定：监视某物/收集某种凡人气息/养蛊/为某个势力埋钉子）。

顾生**看破了它的本相和阴谋**，但他一个废灵根，**说破没人信**（谁信一个郎中说"镇上的张三是妖怪"），**动手又打不过**。他只能用"看破不说破"的方式——**装作偶然、借刀、布局**——在不暴露自己能力的前提下除掉它。

### 章节推进
| 章 | 事件 |
|---|---|
| 16 | 流浪到苍梧镇。落脚，当郎中，扎根（凡间温情线） |
| 17-19 | 行医+暗修（常规修炼）。古物第二重视界开始解锁，他开始"看见"伪装的痕迹 |
| 20-22 | "看见"镇上某人（卧底）的本相不对。开始暗中观察、拼它的阴谋 |
| 23-25 | 拼清卧底的目的+背后势力。**看破，但不能说**——说了没人信+暴露自己 |
| 26-28 | **布局**：顾生用一个不暴露"我看见了"的方式（借镇上猎户的手/借某次妖兽事件/借卧底势力的内斗），除掉/逼走卧底。**第一次完整的"看破不说破→借刀→翻盘"** |
| 29 | 除掉一个，牵出更大的网——卧底背后有势力，苍梧镇的危机不是孤立的 |
| 30 | **Arc2收尾**：顾生意识到自己已卷入更大的棋局，无法独善其身 |

### Arc2要解决的设计问题
- 卧底的具体身份/形态/阴谋目的
- 顾生"借刀"的具体手法（要巧妙、要利用看见的信息差）

## Arc 3：棋子（ch31-50）

### 核心阴谋：宗门高层阴谋链
一个牵涉**宗门高层/大势力**的阴谋浮出水面。方向（待定其一或组合）：
- **功法阉割链**：某条功法被谁阉割、为什么、受益者是谁。
- **历史篡改**：某段被抹除的历史（可能与大能有关），有人想让真相永远不见。
- **凡人压制的执行网**：某个长期压制凡人的机制/组织。

顾生**看破了整个阴谋全貌**（第三重视界加深），但这是**最大的"看破不能说破"**——幕后是金丹甚至元婴级的存在，说破=秒死。他用全书至此最大的一次**权谋操作**——连环布局、借多方的力、伪装成各方博弈的自然结果——瓦解阴谋，让幕后互相残杀，自己全身而退。

### 章节推进（框架）
| 章 | 事件 |
|---|---|
| 31-35 | 顾生在凡间站稳（万家城雏形/苏瑶线交叉），古物能力深化 |
| 36-40 | 钩子2酝酿：他开始"看见"功法/历史的篡改痕迹，撞破阴谋的边缘 |
| 41-45 | **钩子2炸**：看清阴谋全貌（中层真相）。巨大的"看破不能说破" |
| 46-48 | **布局期**：憋。顾生暗中串联、挖坑、借力。读者跟着一起憋 |
| 49-50 | **大型权谋战（大爽点）**：阴谋瓦解，幕后互相残杀，顾生全身而退 |
| 50 | **节点②**：瓦解过程中，**有他想救的人死了**（方伯？或其他人），因为他的方式受限。看破却无力 |

### Arc3要解决的设计问题
- 阴谋的具体内容（功法链/历史/压制网，选一个或组合）
- 顾生"连环布局"的具体设计（需精巧、可读）
- 节点②的牺牲者+具体死因

## Arc 4：被注视的眼（ch51-75）

### 双线压迫：外面追 + 里面引
- **外面**：Arc3后，某高层意识到"有人在暗中看破并操纵一切"，开始追查顾生。**中度暴露**降临——"恰好"的追查与顾生的深看时间线高度重合。
- **里面**：古物里的大能开始**提条件**（要顾生去某封印地/找某物），并**选择性透露信息**引导顾生。顾生发现大能给的信息不全可靠。

### 章节推进（框架）
| 章 | 事件 |
|---|---|
| 51-58 | 被追查。顾生在追杀中周旋，用"看见"识破追杀者的布局，反杀/逃脱 |
| 59-65 | 大能开始提条件。顾生两面受压，开始怀疑大能的目的 |
| 66-70 | 顾生发现大能"选择性透露"——它在引导他。**博弈开始** |
| 71-75 | **打脸高潮**：顾生**反过来算计大能**——假装顺从，实际利用大能给的部分信息完成自己的目的，没完全掉进棋局。第一次对金手指反客为主 |
| 75 | **Arc4收尾**：大能半恼半欣赏，透露"你捡到古物不是巧合"。顾生进入"谁都不能信"的最孤立状态 |

## Arc 5：真相与火（ch76-100）

### 终极真相浮现 + 主动赴险
- 顾生看清：秩序是被设定的，未知存在专司清理，他从穿越起就在大能的棋局里。
- 他亲眼目睹一次**未知存在的"清理"**（某人被从所有人认知里抹去，只他记得）——**真正明白自己玩的是什么火**。

### 章节推进（框架）
| 章 | 事件 |
|---|---|
| 76-85 | 终极真相层层浮现。顾生拼出大能棋局+未知存在之网+秩序之锁的全貌 |
| 86-90 | 目睹"清理"。恐惧达到顶点。但也看清——要破局，必须主动深看终极真相 |
| 91-95 | 准备+布局。顾生为主动深看做一切准备（护住在乎的人、留后手） |
| 96-99 | **节点③**：顾生**主动选择深看终极真相**，明知会暴露。他看见了，也被锁定了 |
| 100 | **第100章收尾**：带着终极真相，独自面对即将到来的"清理"。**不是绝望，而是"我知道这一仗怎么打了"的冷峻**。读者带最大悬念进入下100章 |

### 第100章钩子设计（待定方向）
- 选项A：顾生看见终极真相后，发现打破秩序的关键点——但他必须做一个"看似自毁"的选择。
- 选项B：顾生发现大能的真实目的与他以为的不同——终极反转。
- 选项C：未知存在的"清理"降临，顾生用他布局的后手，**硬扛下第一波**——证明"窥探者也能反击"。

## 阴谋故事清单（用户要求：配合几个阴谋故事）

本书的每个"阴谋故事"都是一个完整的**看破→不能说破→夹缝布局→翻盘→代价**循环。已规划的核心阴谋：

1. **Arc1：清除名单**（宗门对边缘者的例行清除）
2. **Arc2：苍梧卧底**（披皮妖物的长期渗透）
3. **Arc3：功法/历史阴谋链**（高层掩盖真相的大阴谋）—— 主菜
4. **Arc4：双面棋局**（外面追杀+里面大能引导，顾生反算计）
5. **Arc5：终极真相**（秩序、未知存在、大能棋局）

每个阴谋都要有：**一个伪装得很好的反派/幕后、一层层剥开的真相、顾生看破后的憋屈与翻盘、真实代价。**
