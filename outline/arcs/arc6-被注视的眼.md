# Arc 6：被注视的眼（~ch93-115，阴谋主导）

> 隶属 `../总纲.md`。冲突时以 `../../story/SPINE.md` + `../../worldbuilding/` 为准。
> 护法网成撤离/传讯基础。中度暴露弧。

---

## 核心阴谋：外面追 + 里面引（大能博弈）
- **外面**：Arc5 的追查升级为**中度暴露**——"恰好"的追查与顾生的深看时间线高度重合。但追查对象仍是"能力痕迹"，绝不让中高层拼成"假死的顾生还活着"（后期死局节点）。
- **里面**：照墟玦里的大能开始**提条件**（要顾生去某封印地/找某物），并**选择性透露信息**引导顾生。顾生发现大能给的信息不全可靠。
- 本弧惊险**不是肉身追杀逃命**，而是顾生在"被追查的能力痕迹"与"大能的引导"两面受压下，**看破不能留痕**地周旋。

## 暗流（妖兽线）：护法网成撤离/传讯基础
- Arc5 收拾后的护法网，本弧成为顾生的**撤离 / 传讯 / 情报基础**——危急时妖护法网替他打掩护、传消息、转移焦点。

## 章节推进（框架）
| 章 | 事件 |
|---|---|
| 93-100 | 中度暴露降临。顾生用"看见"识破追查者布局，**掐断快要被拼上的痕迹链**，不是肉身逃杀；追查者只确认"有人异常"，拼不出"顾生活着" |
| 101-108 | 大能开始提条件、选择性透露。顾生两面受压，怀疑大能目的；大能可暧昧点出香火/民心像一层挡风的暖雾，但不解释机制（**信仰喂照墟玦**暗线第一次明确暗示） |
| 109-113 | **打脸高潮**：顾生**反过来算计大能**——假装顺从，实际利用大能给的部分信息完成自己的目的，没完全掉进棋局。第一次对金手指反客为主。借护法网安排撤离/传讯 |
| 114-115 | **Arc6收尾**：大能半恼半欣赏，透露"你捡到照墟玦不是巧合"。顾生进入"谁都不能信"的最孤立状态 |

## Arc6要解决的设计问题
- 大能提的"条件"具体是什么（某封印地/某物）
- 顾生"反算计大能"的具体手法
- 护法网作为撤离/传讯基础的具体一次用法
