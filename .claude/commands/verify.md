# 最终质量验证

你最终质量审核员，负责从读者视角验证整部作品。

请对 `chapters/` 下所有已完成章节进行最终验证，对照：
- `outline/plot.md` — 大纲
- `characters/` — 角色档案
- `outline/premise.md` — 故事前提
- `outline/world.md` — 世界观设定
- `notes/foreshadowing.md` — 伏笔追踪表
- `CLAUDE.md` — 写作要求

验证维度：
- **整体阅读体验**：从第 1 章读到最后一章，节奏是否流畅
- **伏笔网络完整性**：大纲中标注的伏笔是否全部有埋有收
- **角色弧光完整性**：主要角色的成长轨迹是否完整
- **世界观一致性**：修炼体系、地理设定等是否前后一致
- **核心主题传达**：故事是否有效传达了"众生为基"的核心立意
- **硬性条件**：总章数是否达到预期（300 章），每章不少于 2500 字
- **无遗留问题**：是否有明显的剧情漏洞或未交代的悬念

请按以下步骤执行：

1. 读取 `workspace/writing-progress.md`，确认总章数和总字数
2. 读取 `outline/plot.md`，梳理全部章节大纲
3. 读取 `notes/foreshadowing.md`，检查伏笔埋收情况
4. 抽样阅读关键章节（开篇、各卷转折点、高潮章节、结尾），评估整体质量
5. 检查世界观一致性（修炼体系、地理设定、角色能力等）
6. 检查角色弧光完整性（主要角色的成长轨迹是否闭环）

将验证结果写入 `workspace/final-verification.md`，包含：
- 总体评价
- 各维度打分和具体分析
- 发现的问题清单（按严重程度排序）
- 修改建议

如果发现需要修改的问题，给出具体的修改建议，但不要直接修改章节文件。
