# 章节格式修复标准

## 适用范围

本标准适用于 `output/chapters/` 下所有章节的格式修复。

## 问题诊断

部分章节存在两个系统性问题（在最后10章尤为严重）：

1. **"——"（破折号）被滥用为短语分隔符** —— 几乎每两个短语之间都用"——"，正常应该用"、"或"，"
2. **"几个字站一行"** —— 每个意象、每个短语都独立成段，用"——"首尾包围，形成诗化断句

在最后10章中，第291-293章主要问题在"——"过多，**第294章**开始断句蔓延，**第295-300章**已经接近纯诗体，段落结构完全崩溃。

## 修复原则（必须严格遵守）

### 原则一：标点的真实语义

| 原文情况 | 处理方式 | 说明 |
|---------|---------|------|
| 句末"——" | 改为"。" | "——"不是合法的句末标点 |
| 句中作停顿的"——" | 改为"，"或"、"| 顿号用于并列短语，逗号用于其他 |
| 单独的"——"行（段落分隔符） | **删除整行** | 段落用空行分隔，不需要"——"做分隔 |
| 解释、补充的"——" | **保留** | 如"以天地灵气为基——"中的"——"是真实破折号 |
| 对话前的"——" | **保留** | "——是。"这种是标准对话格式 |
| 语气突然中断 | **保留** | "不——"、"我——"这种带情绪的中断 |
| "他——"插入人物动作 | 保留为"，" | 如"他——笑了" → "他，笑了" 或合并 |

### 原则二：段落的重新组织

**核心动作：合并同一语意段内的所有断句为一个自然段落。**

判断标准（满足任意一条即可合并）：
- 表达的是同一件事、同一动作、同一画面
- 前后句有明确的主谓承接关系
- 去掉"——"后直接相连是通顺的中文
- 中间没有时间跳转、场景切换、人物视角变化

**保留为独立段落或短句的情况**：
- 时间跳转（"三天后。"、"那天傍晚。"）
- 场景切换（"与此同时——沈青衣在灵药田里。"）
- 关键情绪节点（"现在。"、"然后。"、"到了。"这种咏叹式的单字）
- 强抒情效果的刻意留白

### 原则三：节奏感的保留

**这是最微妙但也最关键的一点**。原文的"短句节奏"不是要全部消除——它在某些地方是有效的抒情手法（如证道、灵雨、玉佩、归一这种诗意章节）。

判断方式：
- **删去"——"和换行后，原文是通顺的叙述** → 合并为正常段落
- **删去"——"和换行后，原文依然保留了断句的咏叹效果** → 保留为短段落，但删除"——"

### 原则四：风格统一

修复后必须与小说整体的叙事风格保持一致：自然段落、标点规范、断句节制。

## 修复示例

### 示例1：严重断句合并

**原文**：
```
苍梧镇——

他来的时候——三百人——几间泥墙草屋——

方伯背着他走过的路——
```

**修复后**：
```
苍梧镇。他来的时候，三百人，几间泥墙草屋，方伯背着他走过的路。
```

### 示例2：诗化断句整理

**原文**：
```
不——比那更温暖——

是——被天地——

接纳了。
```

**修复后**：
```
不——比那更温暖，是被天地接纳了。
```

或更彻底：
```
不，比那更温暖，是被天地接纳了。
```

### 示例3：对话保留

**原文**：
```
她没回头——

"你回来了？"她说——
```

**修复后**：
```
她没回头。
"你回来了？"她说。
```

### 示例4：动作插入处理

**原文**：
```
方远把刀——

轻轻——

放在坟前。
```

**修复后**：
```
方远把刀轻轻放在坟前。
```

或保留一点节奏：
```
方远把刀轻轻放在坟前。
```

### 示例5：独立段落分隔行处理

**原文**：
```
炒完最后一粒种子——他站起来——擦了擦手上的泥——往山下看。

万家城在山脚下——灰色的屋顶——白色的墙壁——金色的城墙在阳光下微微发光——

炊烟从各处升起来——
```

**修复后**：
```
种完最后一粒种子，他站起来，擦了擦手上的泥，往山下看。

万家城在山脚下——灰色的屋顶，白色的墙壁，金色的城墙在阳光下微微发光。

炊烟从各处升起来。
```

### 示例6：场景切换的"——"

**原文**：
```
方婶的粥——也该好了。

——

他加快了脚步。
```

**修复后**：
```
方婶的粥也该好了。

他加快了脚步。
```

### 示例7：咏叹式单字保留

**原文**：
```
她不知道这条路能不能走通——

但她——

在走。
```

**修复后**：
```
她不知道这条路能不能走通，但她——在走。
```

或保留为短句：
```
她不知道这条路能不能走通。

但她——在走。
```

### 示例8：解释性破折号保留

**原文**：
```
他闭上眼睛——盘膝坐下——像在苍梧镇给人把脉时的姿势。
```

**修复后**：
```
他闭上眼睛，盘膝坐下，像在苍梧镇给人把脉时的姿势。
```

或保留破折号：
```
他闭上眼睛，盘膝坐下——像在苍梧镇给人把脉时的姿势。
```

## 修复步骤

1. **完整读取原文**（不要跳读或抽样，必须读完整章）
2. **识别段落结构**（找出场景切换、时间跳转、关键情绪节点）
3. **逐段合并断句**（按"原则二"和"原则三"判断是否合并）
4. **标点规范化**（按"原则一"替换或保留"——"）
5. **删除孤立"——"行**（纯粹作为分隔符的"——"行整行删除）
6. **复读一遍**（修复后必须读一遍，确认节奏感和可读性）

## 验收标准

修复后必须满足：

- [ ] 段落结构回归正常叙事节奏（每段至少2-3句话，除非是短句咏叹）
- [ ] 标点规范（句末用"。"，句中用"，"或"、"，破折号仅在真实需要时使用）
- [ ] 没有"几个字站一行"的情况（除了刻意的短句咏叹）
- [ ] 对话、引用、特殊破折号保留原样
- [ ] 原文的节奏感和抒情意境得到保留（不是消除诗化，是修正过度的诗化）
- [ ] 修复后能直接朗读，不会有"读起来像诗不像小说"的违和感

## 重要提醒

**绝对禁止**：
- ❌ 用代码批量替换"——"为"，"或"。" —— 这是字符级操作，会破坏语义
- ❌ 完全消除诗化断句 —— 原文的抒情效果要保留
- ❌ 改写原文内容 —— 这是格式修复，不是文笔润色
- ❌ 删减情节或对话 —— 修复后字数应该和原文相近

**必须做到**：
- ✅ 读完整章后再动手
- ✅ 逐段判断是否合并
- ✅ 保留对话和真实破折号
- ✅ 修复后复读一遍
