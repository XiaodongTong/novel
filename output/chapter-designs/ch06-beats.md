# ch6-beats —— 坠崖与眼·第六章

## 强制项 1. 目标情绪
- **情绪**：震撼 → 警觉
- **强度**：4
- **读者身体反应**：屏住呼吸看主角第一次"看穿"阵法

## 强制项 2. 信息差
- **读者比刘波多知道**：读者第一次看到"阵法维度解锁"
- **对手不知道刘波知道的**：刘波能看见顾长缨布的清除暗阵

## 强制项 3. 节拍（4个）
1. **暗阵出现**——刘波夜里"看见"杂役院后山方向有某种阵法的痕迹，这阵不是保护人的，是"清除"用的
2. **看穿结构**——他第一次用碎片"看清"了阵法的结构——几个关键节点，正好对应他观察到的"失踪地点"
3. **看见不能破**——他发现自己只能看穿，但无法破坏；这是"看见≠能动"的硬上限第一次展示
4. **藏伏笔**——他悄悄把一枚林阿木留下的遗物藏了起来

## 强制项 4. 主角决策点
- **两难**：发现了阵法的存在，但要告诉谁？
- **他选择**：不声张，但留证据
- **放弃的备选**：向某个管事告发——风险太大
