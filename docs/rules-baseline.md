# rules-baseline —— 规则基线（情节/格式硬约束）

> 与 `voice-baseline.md`（声音规则）平行，本文件管**情节与格式**层面的硬约束。
> 扩写前必读——只回看 voice-baseline 20 条 + 本文件 N 条，避免扩写时变机械。

---

## 一、代价铁律（1 条）

1. **代价只能主角扛**，绝不转嫁给他名义上守护的人。

---

## 二、反派铁律（1 条）

2. 反派不降智（元婴长老不会信"做梦瞎猜"那套）。

---

## 三、开篇铁律（1 条）

3. 章首三行内必须有事发生（禁天气 / 心理回顾 / 景物描写开章）。

---

## 用法

- **写章节前**：与 `voice-baseline.md` 一起回看，扩写时两条基线一起管。
- **修改本章基线**：在 `docs/审稿-checklist.md` 找对应检查项；如要新增条目，先在 `CLAUDE.md` §五铁律登记，再回填本文件。
- **不要在本文件重复展开剧情细节**——本文件只承载"硬约束"那一句话，详细写法在 `../story/STYLE-GUIDE.md`。
