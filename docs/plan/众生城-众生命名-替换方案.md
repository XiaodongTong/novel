# 命名替换执行方案

> 把"众生"开头的组织/丹药/学堂名替换为更有品味、更朴素的命名
> 创建日期：2026-06-11

## 0. 总览

- **替换**：众生城→万家城，众生丹→济世丹，众生学堂→明德学堂
- **范围**：`chapters/` + `meta/` + `review/` + `summaries/`（全量）
- **核心原则**：先手修高风险 9 处 → 再机械替换 → 再验证
- **预估工时**：约 40 分钟

## 1. 替换/不替换清单

### 1.1 严格替换（3 个术语）

| 现名 | 新名 |
|------|------|
| 众生城 | 万家城 |
| 众生丹 | 济世丹 |
| 众生学堂 | 明德学堂 |

### 1.2 严格不动（边界保护）

以下"众生X"**绝对不动**：

- 修炼概念：众生道、众生金丹、众生元婴、众生为基、众生之力、众生意志
- 实体组织：众生盟、众生军、众生壁
- 抽象用法：众生（独立成词）、众生相、众生皆、众生命、众生苦 等

> sed 命令中只匹配完整 3 字 / 4 字词，不会误伤"众生"二字。

### 2.2 章节文件名（1 处）

- 文件内第 1 行章节标题同步改

## 3. 机械替换（sed）

```bash
cd /Users/russell/workingspace/novel/output

# 1. 备份（务必先做）
cp -r chapters chapters.bak
cp -r meta meta.bak
cp -r review review.bak
cp -r summaries summaries.bak

# 2. 机械替换（三个互不交叉，顺序无所谓）
find chapters meta review summaries -type f -name "*.md" -exec sed -i '' \
  -e 's/众生城/万家城/g' \
  -e 's/众生丹/济世丹/g' \
  -e 's/众生学堂/明德学堂/g' \
  {} +

# 3. 重命名章节文件
cd chapters && mv "第163章 众生城扩建.md" "第163章 万家城扩建.md"
cd ..
```

## 4. 需决策的点

### 4.1 「众生之城」（共 4 处）——旗上/描述用词

旗上"众生之城"是独立的精神符号，**已确认的 4 处用法**：

- 旗面："那旗帜是淡金色的...上面绣着的四个字——'众生之城'——"（最关键的招牌画面）
- 描述："那是众生之城两万居民的缩影"
- 另外 2 处执行时再 grep 全文确认

**两个选项**：

- **A. 保留"众生之城"**（推荐）：官方地名是"万家城"，旗上写"众生之城"——形成**"名/实"分离**，名是万家万户的烟火气，"众生之城"是精神高度，反而有立意
- **B. 全部改为"万家之城"**：完全统一，但失去对比张力

**默认方案 A**——若执行时决定改 B，sed 一行命令即可：
```bash
find chapters meta review summaries -type f -name "*.md" -exec sed -i '' 's/众生之城/万家之城/g' {} +
```

### 4.2 plot.md 命名叙事需改写（必须）

`summaries/plot.md:1618` 原文：

> 苍梧镇...凡人口中它有了一个新名字——"众生城"。因为这里不分修士与凡人，不分灵根优劣，只分守护者和被守护者。

替换后需要补一句解释"万家"的含义（这是核心立意承载段）：

> 苍梧镇...凡人口中它有了一个新名字——"万家城"。因为这里不分修士与凡人，不分灵根优劣，只分守护者和被守护者——万家万户，共此一城。

> 注：执行时按上面润色即可。如想更诗意可改：
> "万家灯火，皆是归处"
> "此城无主，万家为主"
