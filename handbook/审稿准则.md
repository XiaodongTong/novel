好故事的标准只有一个——读者放不下、忘不掉、想安利。

所有技巧、结构、主题，最终都要服务于这三个检验。

---
一、主编的三问（最高标准）

每次我决定要不要录稿，只问自己三个问题：

1. 读完之后记住了什么画面？ —— 记住的是"主角握着那把钥匙站在雨中"，还是"情节是 A 杀了 B"？能记住画面，才算有故事。
2. 我在乎这个角色的命运吗？ —— 不在乎，就什么都没了。
3. 我会把这本书推荐给朋友吗？ —— 犹豫一秒，就过不了。

如果一个故事能过这三关，技巧上的小毛病都可以修。过不了这三关，技巧再花哨也是废稿。

---
二、好故事的六个核心特质

按重要性排序：

1. 冲突是故事的发动机（最核心）

没有冲突就没有故事。冲突的本质是"角色想要某样东西，但被某样东西阻挡"。

- 冲突必须逐级升级 —— 第二场戏的赌注必须比第一场高
- 失败的代价必须清晰可感 —— 读者要知道"如果主角输了，会怎样"
- 冲突必须是主角自己选择的产物 —— 而不是天上掉下来的灾难

▎ 反例：车祸、绝症、飞来横祸，这些不是冲突，是突发事件。真冲突是"主角明知道会死，还是要走进那扇门"。

2. 角色是被冲突塑造的弧线

好故事讲的不是"发生了什么"，而是"这个人因为发生了什么而变成了什么"。

- 主角必须有清晰的欲望 + 真实的困境 + 内心的矛盾
- 故事结束时的角色，必须和开始时不一样
- 配角不是工具人，要有自己的"小欲望"

▎ 一句话总结：角色是车，冲突是路，弧线是开完这段路之后，车里的汽油还剩多少、轮胎磨成了什么形状。

3. 「展示」而非「讲述」是分水岭

这是业余作者和职业作者最大的分界线。

- ❌ 讲述："他非常悲伤，眼泪流了下来。"
- ✅ 展示："他把结婚照翻过去，扣在桌上那张外卖单上。"

规则：每当你写下"感到""觉得""非常""无比"，停一下。用一个动作、一个细节、一个物件去替代。

4. 细节是故事的肌理

- 好的细节是具体、独特、有功能性的 —— 既真实可信，又推动情节
- 差的细节是模糊、笼统、装饰性的 —— "那是一个寒冷的夜晚"什么都说明不了，"那天是 1998 年 1 月 17 日，他记得是因为那天她穿了一件红毛衣"才是细节

▎ 规则：每场戏至少有一个只有这个角色、这个时刻才会有的细节。

5. 节奏是看不见的推力

- 好节奏 = 信息密度恒定 —— 读者永远
- 拖沓 = 该快的地方慢（铺垫、过场戏）
- 仓促 = 该慢的地方快（情感高潮、关
- 短句加快节奏，长句放慢节奏。靠句式控制呼吸，不是靠字数。

6. 主题是读后浮上来的余味

- 主题不该被说出来，该在故事结束时被读者自己感觉到
- 最忌讳：角色变成作者的传声筒，对话
- 最好的主题是用情节本身去论证 —— 不必说出来，读者会自己得出

---
三、红队挑刺（强制找茬层，在三问之前执行）

> 三问是事后自评，必然放水——谁会承认自己写的"不值得推荐"？
> 所以在三问之前，先做**红队挑刺**：强制找茬，找不到=没认真读。
> **判定逻辑反转**：旧逻辑是"找不到大毛病就过"；新逻辑是"**说不出3个让我拍腿的具体瞬间 + 指不出至少2个具体问题，就打回**"。

### A. 找不到这3个"拍腿瞬间"，退稿

读完这一章，**必须能说出 3 个让你揪心/憋屈/痛快/意外的具体瞬间**（不是情节梗概"他反杀了"，是那一刻的画面和身体反应）：

1. 哪一刻替主角捏了把汗/攥了拳？
2. 哪一刻想骂人/拍腿/骂反派不是东西？
3. 哪一刻出乎你意料（你猜不到接下来会这样）？

> 三个都说不出来 = 这章平，没有钩住读者的瞬间，**退稿**。
> 说得出来但全是"事后回想才觉得"，不算——必须是读的时候当场发生的。

### B. 必须指出的4类问题（指不出=你没认真审）

读完这一章，**必须主动找出**以下4类问题，每类至少1条：

1. **走神点**：我在哪一段想跳过/读不下去/眼睛发飘？为什么？（找不到=你在敷衍读）
2. **从容点**：主角在哪一刻太从容、太全知、太"我早看穿了"，让我出戏？（主角不能是上帝）
3. **假点**：这一章最假的细节是哪个？哪个对白/动作/反应你根本不信？（细节不真=故事不立）
4. **套路点**：哪一段你在别的网文里见过八百遍了？哪句话是"水文套话"？

> 4类全指不出来 = 你没有以挑剔读者的身份读，**重审**。
> 指得出来，但每条都是"基本还好"这种和稀泥的话 = 没认真，**重审**。
> 必须具体到"第X段那句Y话，因为Z，假/平/套路"。

### C. 反派力度专项（爽点的另一半）

爽点 = 憋屈强度 × 翻盘落差。**憋屈靠反派给**。所以单独查：

- 这个反派/对手，这一章做了什么让我恨得牙痒的具体事？（不是"他很坏"，是具体的恶）
- 如果我不恨他，主角打赢他我也不痛快——**这章爽点废了**，退稿。
- 反派有没有自己的算计/腔调/毛边？还是只是个"等主角来打"的木偶？木偶反派=退稿。

四、评判标准的层级（决策树）

我自己的决策树，按这个顺序判断：

┌──────────┬────────────────────┬───
│  优先级  │       判断项       │        不达标怎么办         │
├──────────┼────────────────────┼───
│ 一票否决 │ 角色命运我是否在乎 │ 不在乎 → 退稿，无论其他多好 │
├──────────┼────────────────────┼───
│ 一票否决 │ 核心冲突是否升级   │ 平推 → 退稿                 │
├──────────┼────────────────────┼───
│ 一票否决 │ 结尾是否成立       │ 烂尾/仓促 → 退稿            │
├──────────┼────────────────────┼───
│ 重要     │ 「展示」是否到位   │ 大量讲述 → 退修             │
├──────────┼────────────────────┼───
│ 重要     │ 节奏是否失控       │ 有拖沓段 → 退修             │
├──────────┼────────────────────┼───
│ 加分     │ 主题是否有余味     │ 直白说教 → 微调             │
├──────────┼────────────────────┼───
│ 加分     │ 语言是否有辨识度   │ 平庸 → 微调                 │
└──────────┴────────────────────┴───

▎ 关键点：前三条是硬性门槛，过不了就 是为什么"故事讲得好"和"文笔好不好"是两件事。

## 五、网文硬指标审查（战斗胜利必有收获）

> 本节是网文特有的硬约束，不在通用文学叙事的"六特质"框架内，但与一票否决项同级——**违反即退回**。

### 判断项
**战斗胜利是否有可数收获**（功法/法宝/丹药/灵石/妖核/情报/资源，任一）。

- 每次打架/斗法获胜后，必须当场或紧接章清点战利品——逐一列出，**可数、可触、可描述**。
- 绝不接受"收获颇丰""大获全胜"这种一笔带过的水文。
- 写法样板见 `style/beats-library.md`「收获兑现节拍」（类型 7）。
- 规则依据：`style/rules-baseline.md` §四第 9 条 + `AGENTS.md` §4.1 第 11 条。

### 例外（仅当满足以下全部条件时允许"留不下来"）
1. 该次"留不下来"服务于特定情绪弧（如 Arc1 ch9 被迫上交、某重要角色死的无奈）。
2. 正文必须明确写出"他本可拿"和"为什么没拿/拿不住"。
3. 该收获须在后续弧以其他形式补回。

### 无形收获也算
顿悟/自创心法（如 Arc7）算合规收获，但须可描述、可兑现为下一阶段实力。

### 不达标怎么办
**退修**——补出战利品清点段（按「收获兑现节拍」四步：胜利→清点→满足感→埋用场）。

---
四、给作者的一个简单自测法

把稿子放一周，再拿出来问自己：

1. 用一句话讲这个故事给我听 —— 说不
2. 这场戏的冲突是什么 / 角色想要什么 —— 说不出来，这场戏就删掉
3. 删掉任何一章故事还成立吗 —— 成立
4. 结尾是唯一合理的结局吗 —— 不是，重写

▎ 编辑三十年最深的体会：好故事不是写出来的，是删出来的。

写在最后

评判标准听起来很多元，本质就是三件事

- 角色让我在乎（人物）
- 冲突让我紧张（张力）
- 细节让我相信（真实）

能做到这三点的稿子，我闭着眼睛都签。 。
