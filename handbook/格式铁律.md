# 格式铁律

> 正文成品的格式硬约束。与小说内容无关，独立维护。
> 扩写、审稿、改稿任一环节发现违反 → 必须清除。

---

## 1. 文件格式
成品必须以 txt 格式输出，命名 第N章 标题.txt。旧版 .md 文件已全部删除。

## 2. 正文内禁止任何 markdown 标记
txt 是纯文本正文，不是渲染目标。禁止的字符/组合包括但不限于：星号对（如 **xxx** 加粗、*xxx* 斜体）、井号行首（# 标题）、反引号（ 代码 ）、方括号链接（[文字](url)）、行首 > 引用、连续三个 - 的分隔线、行首 - 或 1. 的列表项、图片语法（![图片](url)）、删除线（~~删除~~）等所有 markdown 语法。

要"强调"靠语境 + 句式 + 标点（顿号、问号、感叹号、引号），不靠字符。

## 3. 字数
每章 **2500–3000 字**（含标点）。
- 短于 2500 → 检查：是否在用短句成段滥竽充数？是否意境不足？
- 长于 3000 → 检查：是否灌水？是否意境堆砌？

## 4. 段落长度规范
- **"短句独立成段"是稀有事件，不是基线**。使用场景仅三处：
  1. **决断**（一句一行的命令、承诺、拒绝；"朕不走。"）
  2. **沉默**（人无语 / 景无声；山门没开。）
  3. **章尾收尾**（最后两到三行制造余响）
- **基线段落**："长短句交错的一整段"——4 到 8 句为宜。动作/写景/心理/对白都可以合并在同一段里。
- **写景段**：可以独立成段，但段内**至少 3 个画面**（不是单句成段）。
- **心理段**：禁止连续 3 个以上的"短句独段"——心理是有过程的，要让过程在句子里流动，不要在行里切碎。
- **段间空一行** 强制：每个段落之间必须空一行；不要把空行省略成单换行。

## 5. 破折号（——）规范
- **整章出现次数 ≤ 6**。破折号不是段间隔符，是"语气顿挫"。
- **只能用于以下三类位置**：
  1. **引出一句话顿悟/一句话反转**（他今日忽然明白——这一程路，走到头了）
  2. **对白被打断或补充**（"我——"他没说完。）
  3. **章尾的最后一次留白**（山门合上的那一刻——山门外的雪——停了半息。）
- **禁止用于**：
  - 段间分隔（用空行）
  - 解释/补充说明（用逗号或句号重起一句）
  - 列举（用顿号或句号）
  - 拟声/状态描述（用句号或逗号）
