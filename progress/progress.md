### 第二明线：救苦救难 → 妖兽点化 → 护法教 → 万民胚胎（独占 Arc3/5 主导弧）
> 详见 ../base/spine.md §六「前段结构」与 §十「执行索引」。**不是副线，是与阴谋线并列的第二明线。**
- **五阶段映射**：萌芽(Arc2尾-Arc3头) → 成形(Arc3) → 扩张(Arc5头) → 失控(Arc5) → 跨界(Arc7)。
- **命名规约**：正文一律称**妖兽**（不用山精野怪/小土地/庙祝残魂）。妖兽和人一样分好坏，杀恶妖、点化善妖不是双标。
- **创世故事**：蠢萌妖父子（第一护法起源，9 步骨架见 spine）——暖+萌+喜剧，与阴谋线冷调对照；护法冒充必须建立在 Arc2 后半已铺开的救苦口碑、无名牌位/小龛和零散香火上。
- **两条护栏**：①假死识破=前段之后，前期追查只追"异常看见者"锁不到人；②救苦/点化动机永远是"处理眼前危机/没舍得杀"，不解释功德机制、不出三段式神号、不绑万仙宗身份。
- **两条暗线**（前期只埋、Arc7揭破）：信仰暖意微弱缓冲深看寒意（埋"信仰喂照墟玦"）；神名/护法网=后期"万民之主"胚胎。

### 第三明线：实力成长（脊柱级·八维·纵贯七弧）
> 详见 [../base/world/04-修炼成长.md](../base/world/04-修炼成长.md) 与 [../base/spine.md §六.A](../base/spine.md)。**主角第一要务**——但**实力 ≠ 修为**。
- **八维**：修为 + 功法 + 法宝 + 攻击 + 防御 + 逃跑 + 幻术 + 阵法。修为只是其中一维。
- **境界上限**：七弧最高停在**筑基大圆满**（金丹留后期）。但**八维实力远超同阶**——**可越阶战斗**（短时战金丹后期/元婴初期，逃元婴中期）。
