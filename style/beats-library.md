# BEATS-LIBRARY —— 节拍样板库

> 本文件提供**6 类节拍样板**，写章节时的结构参考。
> 每类给「结构 + 情绪标签 + 关键约束 + 场景示例」。
> 与 style-guide.md 的"看破不说破"5 步互补，本文件覆盖更全的场景。

---

## 节拍类型 1：「看破不说破」标准 5 步（基线节拍）

> **来源**：STYLE-GUIDE §二 已列，本节作为结构模板独立抽出。

### 结构
1. **看见**：刘波用古物看见了某人的算计/某事的真相（用"看见"的感官描写，不要解释机制）。
2. **判断**：他在心里快速判断——说破的后果、装傻的好处、能不能利用。
3. **装**：他选择**不说破**。表面上，他表现得像"什么都不知道的废灵根"。
4. **布局**：他利用看见的信息，在不暴露"我看见了"的前提下，悄悄反制/借力/挖坑。
5. **翻盘**：算计他的人，反被他算计。而他全程**一脸无辜**。

### 读者情绪曲线
- 第 1-2 步：憋（读者也跟着憋，跟着判断）。
- 第 3-4 步：憋到顶（读者想替他掀桌但知道不能）。
- 第 5 步：爆（爽点爆发）。

### 关键约束
- 写"装"的时候，要写出**憋屈感**——他明明知道，却要装不知道，那种忍，要让读者跟着一起憋。
- 翻盘那一刻的爽，是憋出来的。
- **禁忌**：不要让刘波"看见就赢"。看见只是开始，他还要忍、要装、要布局、要承担代价。

## 节拍类型 2：打脸高潮结构

### 结构
1. **铺垫（对手建立优越感）**：对手当众嘲笑 / 显摆 / 挑衅 / 欺压，让读者觉得"这人太嚣张了"。
2. **刘波隐忍**：他忍了。表面上配合 / 装傻 / 不接茬。
3. **触发条件**：对方踩到刘波的底线（比如涉及到他在乎的人 / 涉及暴露底线）。
4. **反制（用看见的信息）**：刘波用古物"看见"的信息，**"无意"**点破某件事（一句话 / 一个动作），让对方立刻露馅。
5. **对方失态的具体动作 + 旁观者的具体反应**：打脸必须**具体到人 + 具体到物**。

### 关键约束
- 不要"全场震惊"——要"顾长缨的脸色从白到青"。
- 反制必须看起来**像偶然**，不能让对手反应过来"他怎么会知道"。
- 旁观者的反应是爽感的放大器——必须有具体的人（不只是"大家"）。

### 场景示例
> 顾长缨当着三个师弟的面嘲笑刘波"废灵根还敢站这里"——刘波忍。顾长缨伸手要推他时，刘波"无意"点破他灵力走偏、让对面弟子脸色一变；顾长缨当场失态，嘴角抽了一下。

## 节拍类型 3：反预期反转手法（5 种）

> 每章反预期至少 1 处，且必须落在某个具体节拍上，不能散在文中。

### 1. 身份反转
- **定义**：以为 A 其实是 B。
- **示例**：刘波以为顾长缨就是命令源头，深看后发现——他只是执行者，真正的命令来自一个他从没见过的"上面的人"。

### 2. 能力反转
- **定义**：以为他没这个其实有。
- **示例**：以为刘波只是个废灵根，看见他用古物识破某陷阱后——他不是"没能力"，是"能力藏得最深"。

### 3. 时间反转
- **定义**：以为还没发生其实已发生。
- **示例**：刘波以为顾长缨还在布局，深看发现——三个月前就已经埋好这颗钉子了，他只是最近才发动。

### 4. 视角反转
- **定义**：读者以为的对是错。
- **示例**：读者以为沈千秋是在帮刘波，看完才发现——他帮刘波是因为刘波恰好符合他另一个目的。

### 5. 代价反转
- **定义**：以为他赢了其实他输了一样东西。
- **示例**：以为刘波反杀成功，看完才发现——他赢了这一局，但他信任的某个人从此不再信他了。

## 节拍类型 4：代价兑现节拍（AI 最易跳过）

### 结构
1. **胜利 / 小爽**：打脸成功 / 反杀成功 / 揭穿成功——爽点爆发。
2. **一行过渡**：用一句过渡句（如"但他没来得及高兴" / "回屋后"）。
3. **代价落地**：具体丢什么 / 失去什么 / 错过什么——必须**可见、可触、可数**。

### 关键约束
- **必须有"代价落地"这一行**，不能跳到下一章让读者自己反应过来。
- 代价不要写"他很难过"——写"他低头，看见自己掌心那道淡黑纹路比昨天深了一分"。
- 代价可以是物件 / 信任 / 机会 / 一段关系 / 一个本可保住的承诺。

### 场景示例
> ch10 刘波用深看反杀试探者成功（爽）。下一行"但他低头时，看见自己掌心那道淡黑纹路比昨天深了一分"（代价落地）——读者跟着爽完立刻一紧。

## 节拍类型 5：钩子四选一硬模板

> 章末钩子必中其一。**绝不断在"他陷入了沉思"。**

### 1. 新信息抛出
- 章末抛一个读者不知道的新信息。
- **示例**：章末刘波回屋，借月光看见掌心有一道淡黑纹路——像一条蜷着的什么东西。

### 2. 新威胁出现
- 章末突然出现一个威胁。
- **示例**：章末他刚以为躲过一劫，转角看见顾长缨就在那里等着——脸上的表情是"我就知道"。

### 3. 主角立 flag / 做决定
- 主角在章末主动做一个决定。
- **示例**：章末刘波盯着掌心那道纹路，对自己说："明天的考核，我去。"——读者立刻想知道他去会怎样。

### 4. 断在动作未完成
- 章末断在一个动作正要发生或未完成时。
- **示例**：章末他伸手去碰那道纹路——指尖刚触到，视野突然黑了。

## 节拍类型 6：节奏对比节拍（解决"一章均匀用力"问题）

> 每章必须有 1 处"快节拍"（短句+动作+紧张）和 1 处"慢节拍"（长句+细节+情绪）。

### 慢节拍示例（情绪 / 画面）
> 刘波在禁地深处回头，看见追到禁地边缘的魏长宁停下脚步——那张脸上没有焦急，只有一种"到这儿就够了"的笃定，好像他早就知道再往里追不划算。

### 快节拍示例（紧张 / 动作）
> 古物钻入掌心的一瞬——疼。然后是冷。然后掌心里有了什么。

### 节奏对比的写法
- **快节拍用句号断句**（短句堆叠）。
- **慢节拍用逗号或破折号延展**（长句延展）。
- 不要在同一节里混用——会让读者不知道该快读还是慢读。

## 节拍类型 7：收获兑现节拍（与类型 4「代价兑现」对偶）

> 战斗胜利必有可数收获（rules-baseline §四第 9 条）。这是网文爽点的核心兑现——**读者跟着主角打完一架，要看他拿到了什么**。类型 4 写"胜利后丢了什么"，类型 7 写"胜利后得了什么"，两者常成对出现（先收获后代价，或先代价后收获）。

### 结构（四步）
1. **胜利瞬间**：杀敌/反杀/破阵成功——爽点爆发。
2. **清点**：逐一列出战利品——功法/法宝/丹药/灵石/妖核/情报/资源，**必须可数、可触、可描述**。绝不能写"收获颇丰""大获全胜"这种一笔带过的水文。
3. **玩家式满足感**：让主角（和读者）有"开箱子"的快感——这件法宝什么品阶、这份丹药能顶几天苦修、这块妖核该怎么炼。这是网文代入感的关键。
4. **埋用场**：为下一阶段埋线——这件法宝下章会用、这份丹药某弧后突破用、这份情报指向下一个目标。

### 关键约束
- **必须有"清点"这一段**，不能跳到下一章让读者自己脑补他拿了什么。
- 清点要**具体**：不说"得了几块灵石"，说"下品灵石一百三十七块，中品三块——够他苦修两个月"。
- 满足感要**落到修炼/实力的具体推进**上：这份收获让他离下一次突破近了多少？补了八维的哪一维？
- **情绪弧例外写法**：当"留不下来"服务于情绪弧（如 Arc1 ch9 被迫上交），写出"他本可拿但没拿/拿不住"——让读者替他可惜，把憋屈感攒到后续补回时一起释放。

### 场景示例
> ch25-27 刘波借刀除掉沧溟三十六寨卧底 cell。胜利后清点三人储物袋——柳七的蛇妖黑鳞核（筑基中后期级，光这一颗就抵他半年苦修）、吴婶的黄鼠狼凝神核（对识海有特殊滋养）、一卷被阉割过的高阶炼气功法残页（照墟玦一照，阉割处清清楚楚）、下品灵石三百二十块、中品十七块、护身玉佩一枚、卧底飞刀三把、还有半袋 cell 从凡人气息里提炼的凝神散原料。他把东西一件件摊在草席上，照墟玦在掌心微微发烫——这是他穿越以来，第一次觉得自己像个真正的修士。

## 用法

每章扩写前，回看本章涉及的节拍类型 1-2 种：
- **阴谋戏**：类型 1（看破不说破）+ 类型 4（代价兑现）+ 类型 7（收获兑现）+ 类型 5（钩子）
- **打脸戏**：类型 2（打脸高潮）+ 类型 4（代价兑现）+ 类型 7（收获兑现）+ 类型 5（钩子）
- **反预期戏**：类型 3（反预期反转 5 选 1）+ 类型 5（钩子）
- **节奏调节**：类型 6（快慢对比）——任何场景都用

**Arc2-5 特有节拍**（如"凡间温情节拍" / "大能碎片节拍" / "未知存在逼近节拍"）后续按需补。
