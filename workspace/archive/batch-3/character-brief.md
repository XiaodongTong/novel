# 人物小传 — 第7-9章

## 顾生

穿越至青玄宗已月余，从最初的迷茫中逐渐站稳脚跟。被分配到药园做杂役后，他凭借前世医学功底获得柳长老的赏识，以助手身份留在药园。近日目睹赵玄机栽赃小陈的整个过程，那种无力感像一根刺扎在心里。他选择用自己能做到的方式回应——为小陈处理伤口。此刻他的心理状态是压抑但清醒的，清楚自己在修仙界的位置：废灵根杂役，连说话的资格都没有。但他同时意识到，前世的医学知识是这个世界里没有人具备的武器。第7-9章中，他将接到整理灵药典籍的任务，并在灵药危机中展现自己的价值。对他而言这不是出风头，是活下去的唯一方式。与苏瑶的相遇则让他第一次在这个冰冷的世界中感受到同类般的温暖。

## 柳长老

青玄宗药园管事，金丹初期修为。活了近三百年，见过太多天才和废柴，但顾生让他眼前一亮——不是因为灵根，而是那种对药理"不讲道理的直觉"。他把顾生留在身边做助手，既有考察之意，也有一丝难以言说的情感——顾生身上那种对草药的精细感知力让他想起年轻时的自己。第5章说的"灵药不认灵根"并非随口之语，而是他几十年药园生涯中悟出的一个与修仙界主流价值观相悖的道理。此刻他给顾生布置整理典籍的任务，表面是普通差事，实际上是想看看这个少年对灵药的理解到底有多深。他观察顾生时的眼神偶尔会变得悠远，像是在看一段尘封已久的往事。

## 赵玄机

秦长老座下弟子，天灵根天才，青玄宗内门中最耀眼的存在。赵玄机的傲慢不是伪装——在一个以灵根论英雄的世界里，天灵根确实让他有资格俯视众人。但最近发生的事让他隐隐不安：一个五灵根废材竟然获得了柳长老的器重。第6章他成功栽赃小陈，碾压蝼蚁的快感还没消散，就被另一种不快取代——柳长老对顾生的态度。赵玄机不是怕顾生，而是无法忍受一个废灵根与自己产生任何可比性。这种嫉恨像暗火一样燃烧，不会立刻爆发，但会持续灼烧他仅剩的耐心。第7-9章中他冷眼旁观顾生的每一次表现，等待合适的时机。

## 苏瑶

柳长老座下内门弟子，双灵根（木水），约28岁（修士驻颜，看似20出头）。苏瑶出身凡人小族，因双灵根被选入青玄宗，从此与家人分离。宗门规矩森严，她已多年未曾回家。在宗门中以炼丹术闻名，讨论药理时眼睛会发光，那是她最真实的模样。性格温柔但不软弱，安分守己但骨子里有钢。第9章苏瑶首次正式出场，在药理课上被顾生的见解吸引，主动找他交流灵药配伍。两人初识时，苏瑶并不知道自己正在遇见一个会改变她一生的人。她只是单纯地觉得——这个废灵根杂役看药的眼光，和她见过的所有人都不一样。
